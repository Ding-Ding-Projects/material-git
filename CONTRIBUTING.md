# Contributing

Read [AGENTS.md](AGENTS.md), the [requirements](docs/requirements/README.md) and relevant action audit. Preserve natural destinations and actual native behavior; a command registry is not the product.

Use a branch/worktree and root build entrypoints. Run type checks and meaningful affected tests locally. Verify changes in the final built interface with isolated profiles. Destructive Git fixtures belong in temporary repositories, never a person's checkout. Do not run remote mutations merely to prove a button exists.

Update accurate articles, roadmap/handoff, inventory rows and evidence limits. Keep credentials, private vocabulary and machine details out of source, fixtures, logs, captures and exports. Public text uses ordinary language and exact technical identifiers.

Describe the concrete trigger, behavior, checks and remaining limits in review. Windows CI is a build/package/publication route, not a test gate. Inventory integrity does not establish complete action parity.
