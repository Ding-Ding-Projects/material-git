# 帳戶語言同精確驗證資料

帳戶面板會跟隨已儲存英文、香港廣東話或雙語設定。應用程式自己寫嘅控制、說明、權限描述、分頁、確認、登入狀態、取消同已知錯誤，都使用獨立帳戶語言資源。雙語操作標籤以英文為主，較細廣東話副標籤放下一行。帳戶同權限搜尋會符合可見翻譯描述同精確識別碼。

帳戶名稱、主機、權限名稱、憑證來源識別同 Git 協定保持精確。已驗證、錯誤同逾時標籤亦顯示服務原本狀態識別。個人用語唔會取代實際 HTTPS 原點或 API 路徑：`github.com` 使用 `api.github.com`；已批准企業主機使用自己嘅 `/api/v3` 同 `/api/graphql`。無效主機名稱唔會啟用登記。已批准主機清單有自己嘅搜尋同 regex 建構器，篩選唔會更改原本選擇。

新增帳戶透過 GitHub 裝置登入，一次性驗證碼只喺目前面板暫時顯示，完成或取消後清除。每個主機有一個使用中帳戶。切換要先檢查帳戶、主機同影響，再獨立確認。指令已經執行時，會保留原本身分。權限更新亦有獨立確認，最低 `repo`、`read:org` 同 `gist` 唔可以移除；重設最低權限唔可以同逐項變更混用。

使用中環境權杖優先於相同主機嘅已儲存帳戶。喺應用程式以外更改環境憑證前，已儲存帳戶切換會停用並解釋原因。移除本機憑證唔代表撤銷 GitHub 權杖。已知原生訊息會翻譯，同時保留精確帳戶事實；未知原生或供應者回應會原文顯示喺已翻譯回應標籤之下，唔會猜測或改寫。

憑證複製係另一個明確確認操作。確認會將可使用憑證交畀原生系統剪貼簿，唔會傳返渲染程序、操作歷史或一般匯出。剪貼簿權限同歷史可能保留內容，使用後要自行清除。企業主機登記只儲存已檢查 DNS 名稱，唔會登入、傳送憑證或略過 TLS 憑證驗證。

專注測試驗證所有支援額外權限、臨時登入同取消訊息、已知錯誤、環境優先同精確資料，以及兩個趣味程度極值。真實 GUI 使用隔離設定同唯讀驗證狀態，唔會開始瀏覽器授權、複製真實權杖、登記主機、切換／移除帳戶或設定 Git 憑證。元件測試資料係獨立證據，唔代表真實已授權帳戶或完成登入。

先執行 `npm run build`，再執行 `node tests/accounts.browser.mjs`。真實帳戶互動測試會透過設定選單儲存三種語言，檢查無障礙名稱、較細下一行雙語標籤、600 像素版面，以及語言變更後保留搜尋、regex 同權限選擇。截圖同唔包含負載嘅驗證紀錄會放喺新臨時目錄。原生狀態機測試指令係 `node --import tsx --test tests/accounts-localization.test.ts tests/auth.test.ts`。共用 regex 工作台說明仍需獨立本地化，呢個帳戶測試唔會聲稱嗰個介面已完成。

原生工作區主機會喺第二版已批准主機記錄儲存；第一版記錄初始仍然選擇 `github.com`。帳戶面板提供已批准選項，同另一個有兩項獨立確認嘅工作區主機檢查。呢個選擇只更改本機情境，唔會登入、切換已儲存憑證、更改環境權杖或登記其他主機。原生服務會驗證精確已檢查名稱，並透過 `selectedHostname` 同 bootstrap `hostname` 發佈選擇。

更改主機會清除已選儲存庫、揀選結果同未提交下載選擇。即使另一主機有相同 `owner/name`，亦要重新明確揀選。執行中要求或下載、未儲存草稿會阻止 GUI 更改情境；原生操作檢查亦會拒絕執行中變更。使用中環境憑證仍然優先，其他主機成功帳戶唔會令目前主機顯示已驗證。

`node tests/host-context.browser.mjs` 使用隔離已批准主機資料，驗證真實 Electron 選擇、兩項確認、原生儲存、工作區主機同重新啟動。測試資料唔包括已儲存帳戶或憑證，唔會登入、切換帳戶、複製憑證、登記主機或更改 Git 憑證助手。資料測試唔代表已連接企業主機或已取得帳戶權限。

原生主機或帳戶情境更改會令 GitHub、API 同 CLI 已儲存檢查全部失效，亦撤銷上載授權。API 面板會關閉可見確認，清除供應者回應同臨時上載識別，保留未提交輸入；請重新選擇上載檔案，再檢查新身分。已批准主機選單仍然保留。CLI 授權使用原生計劃已儲存指令，唔接受 Apply 提供另一個指令。取消操作仍然可用；原生關閉會先安全儲存下載，再取消已擁有 CLI 操作。
