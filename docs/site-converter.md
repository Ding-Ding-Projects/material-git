# Website local file converter

Visitor preferences and Find anything (`Ctrl+Shift+F`) open the website's independent converter. The task workspace remains in this browser while changing website sections. It does not access desktop grants, engines or queues. No selected file uploads or network conversion request occurs.

The categorized catalogue covers structured data/spreadsheets, images, documents/PDF, audio, video, archives, code/text and binary encodings. Each unavailable adapter remains a disabled row explaining its actual missing browser implementation or engine. Enabled destinations accept UTF-8 JSON, JSONL, YAML, the Material Git typed JSON XML schema, CSV and TSV, or inspected PNG/JPEG/WebP images. Structured sources use the shared serializer for JSON, JSONL, YAML, typed XML, CSV, TSV, HTML, SQL, Markdown and plain text when their value shape is compatible. This does not convert arbitrary source code, Office documents or general XML documents.

Admission iterates the browser's FileList sequentially and reads at most 128 KiB of each header. Raster signatures take precedence over names; structured text is a candidate until the isolated worker validates the whole bounded source. Unsupported, empty and over-budget sources are skipped with actual admitted/skipped counts. File arrays are not copied and file bytes are never loaded together. Limits are 8 MiB per source/output, 64 MiB retained sources, 32 MiB retained results and 1 MiB queue metadata. There is no file-count quota. Names are bounded to 1,024 characters. Browser picker discovery still exposes a FileList rather than a native paginated folder grant.

Each task owns its destination. New images default to PNG when a text destination is selected; structured sources default to JSON when an image destination is selected. The catalogue, queue and receipt history each own a text search and adjacent regex builder. Expressions run in a worker with a 256-character pattern and 200 ms total deadline. Category and task-state choices compose with search. Tasks and receipt facts paginate by 20. Task selection supports Material checkboxes, Shift-click/Shift+Space ranges, page/all matching selection, inverse and clear. Selected tasks outside the filter are counted and excluded.

Conversion first reviews the exact selected eligible tasks and destinations. Changing a destination or queue invalidates the review. The review discloses formatting/comment/schema changes, CSV/TSV type loss and formula protection, SQL text without execution, and raster metadata/profile/EXIF removal, animation flattening, 90% JPEG/WebP quality and JPEG's white transparency background. Sources remain untouched. Reviewed destinations lock while the queue runs. Failed and cancelled tasks can be reviewed again.

One dedicated worker runs at a time, with a 15-second deadline and termination on cancellation. Structured data rejects unsafe integers, reserved keys, unsupported YAML tags/aliases, invalid typed XML and malformed delimited records. Shared datum validation caps nesting at 100 and values at 100,000. JSON/YAML/typed XML/JSONL outputs reopen and compare values; CSV/TSV reopen as consistent tables. Other textual outputs use the shared bounded serializer. Raster dimensions are inspected before browser decoding: maximum 4,096 pixels per side and 8,388,608 pixels total. Encoded images reopen to verify dimensions. Browser codec availability can fail honestly at execution. A worker deadline bounds JavaScript execution; it is not proof of operating-system containment of browser decoder processes.

Pause takes effect before the next file and lets the current worker finish. Resume continues only the reviewed task set. Cancel and remove review exact filtered selections; cancellation terminates an active worker, and removal releases selected in-memory sources/results. Completed receipt facts remain. Download hands validated bytes to the browser's download manager. The website cannot verify disk writes, publish a destination folder atomically, detect overwrite decisions or bypass browser download permissions.

The last 200 redacted outcome receipts persist. They contain identifier, time, source/destination formats, byte counts and outcome only. Names, paths, contents and output bytes are excluded from storage, ordinary message history and receipt export. An interrupted marker is saved before each worker starts. Reload loses file permissions and output bytes, so interrupted work explicitly requests source reselection rather than claiming crash recovery. Receipt facts join version 2 visitor transfers and visitor-history snapshots; restoring receipts does not rerun conversions or restore files. Receipt search scopes the actual JSON export.

Office/PDF operations, FFmpeg audio/video, archive expansion, binary codecs, native folder publication, persistent source grants and automatic crash-resume remain unavailable. This is partial browser functionality, not closure of the complete converter requirement. Checks use actual local fixture conversions and downloaded outputs, negative parser/size cases, reviewed effects, independent searches, persistence and a real narrow Chromium capture. Existing navigation-label overlap at 200% text is separately queued.
