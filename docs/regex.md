# Local regular expression workbench

Every `mg-search` exposes its own adjacent Regex button. Plain text remains the default. The anchored workbench edits only that search's pattern and flags. Filtering and sample previews use separate cancellable workers. New requests settle the superseded promise, terminate its worker, and ignore stale replies. Closing or removing the component cancels its preview and teardown cancels both sessions.

The engine is the running JavaScript `RegExp` implementation, not PCRE or RE2. The capability section reports the available Chromium/Electron runtime version and probes actual flags and syntax. Pickers cover tokens, groups, character classes, quantifiers and anchors. Capturing groups, named groups, positive/negative lookahead and lookbehind, numbered/named backreferences, Unicode properties, and greedy/lazy counted repetitions use native engine syntax. Atomic groups, possessive repetition and conditionals remain visibly unsupported with reasons. The flags are `d`, `g`, `i`, `m`, `s`, `u`, `v`, and `y` where runtime-supported; `u` and `v` are mutually exclusive. Filtering resets `lastIndex` for every record. Sticky filtering begins at position zero.

The literal helper escapes metacharacters. Group contents and class members are inserted as expression syntax. Counts accept integers from 0 through 10,000 and reject reversed ranges. Engine validation reports malformed patterns. A lexical token guide explains recognizable fragments; it is explicitly not a full syntax tree.

Sample text displays match count, worker execution time, index ranges, numbered/named captures, and capture ranges when `d` is selected. Previous/Next navigates matches. Replacement preview supports JavaScript replacement templates including `$$`, `$&`, `$1` through `$99`, `$<name>`, prefix and suffix. Preview scans matches for navigation even without `g`, but replacement obeys the selected global flag. No arbitrary code, replacement functions, or eval is accepted.

Each worker has a 250 ms deadline, including startup. Limits are 4,096 pattern characters, 65,536 sample characters, 4,096 replacement characters, 10,000 filter records, 2 MiB aggregate UTF-16 filter input, 200 preview matches, and 262,144 replacement output characters. A timeout terminates the worker and reports a local error. Oversized input is rejected. Bounded preview truncation is reported. Zero-width matches advance one UTF-16 code unit, or one code point with `u`/`v`, so empty matches cannot loop forever. Replacement expansion is checked incrementally to avoid unbounded prefix/suffix amplification.

Snippets are explicitly saved in local browser storage, separately keyed by each search's stable `search-id` or label. They contain only a user-provided name, pattern, flags, sample and replacement. No examples or private defaults ship. Save replaces a same-name snippet. Clear removes the local collection; Reset restores the current workbench to plain text without deleting saved snippets. JSON import replaces the collection only after full validation. Import and cache use schema version 1, reject unexpected fields and unsupported syntax, and accept at most 32 entries and 512 KiB. Each name is bounded to 80 characters; other fields obey the worker limits. Import uses a hidden browser file picker activated by an official Material button. File names and paths are not persisted. Export is an explicit local save via the application bridge. No network request is made.

The builder composes genuine registered Material Web fields, selects, buttons, switches, checkboxes, chips and progress indicators. Browser file plumbing and layout live inside the registered `mg-search` internals. Source tests cover actual engine behavior, invalid syntax, bounded import, replacement semantics, zero-width matching, cancellation races and catastrophic-backtracking termination using a real Node worker. These tests do not establish graphical interaction in Electron, accessibility behavior, overlay placement or design parity; those require a separate real built-artifact verification route.
