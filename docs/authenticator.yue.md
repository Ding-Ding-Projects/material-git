# 本地驗證器項目同受保護備份

本機存取工作區包含原生 TOTP 驗證器。已註冊項目保留確實發行者、帳戶、SHA1/SHA256/SHA512、六至八位數，同所選 1–86,400 秒週期。每項有可編輯標籤、已註冊圖示同可選命名群組。可建立或改群組名、改標籤／圖示／群組、批次移動所選符合項目，同用鍵盤上／下移調整完整已儲存次序。身分同加密秘密保持不變。舊版項目讀取時使用安全標籤預設，下次成功修改先遷移。

獨立文字／正則搜尋旁邊有建立器，群組篩選可一齊使用；每頁二十項。選擇支援本頁、所有符合項目、反選、清除同 Shift 範圍。隱藏選擇保留，但唔包括喺目前篩選操作。普通匯出格式由資料決定，包含標籤、群組名稱／圖示同 TOTP 參數，清楚排除秘密、驗證碼同加密憑證庫內容，無法還原秘密。

註冊接受標準 `otpauth://totp/` URI，或分組 base32 連發行者、帳戶、演算法、位數同週期。URI 參數保持原樣。圖片及剪貼簿圖片由原生回呼讀取，唔接受介面指定檔案路徑；整合無法使用時會清楚顯示。圖片最多 8 MiB；原生適配器會先驗證標頭及更嚴格像素界限，再喺本機 jsQR 解碼。只接受一個可讀有效 TOTP 配對，必須確認目前碼吻合先儲存。

相機只喺執行環境提供媒體擷取，同原生應用程式提供一次性、自有介面、只限影像權限時可用。用戶明確開始，拒絕會如實顯示。影格只喺本機有限解碼；停止、隱藏所屬工作區、頁面不可見或移除控制，會停止全部影像軌。呢個控制唔代表全域授權。

一次性明確顯示會喺本機繪製高對比、有留白嘅 QR，顯示分組手動 base32 同確實參數，QR 有可讀替代文字。改未完成配對會隱藏顯示；註冊或放棄後從記憶體清除，唔會顯示已儲存秘密。驗證碼更新時先作可讀提示；秒數倒數唔會每秒重複廣播。可預覽下一個碼同明確複製目前碼。系統時間未同外部核對，提供者拒絕時請檢查裝置時間。

刪除先由原生審閱確實項目 ID，再用兩把獨立鎖匙同完整滑桿確認。一把鎖匙唔會啟用滑桿，部分進度唔可執行。立即退出／Escape 撤銷審閱同返回原焦點；進度同完成清楚顯示，減少動態會停用動畫。原生資料改變、過期審閱或匯出審閱用嚟刪除，都會拒絕。

受保護備份係獨立命名操作，使用相同確實範圍及確認。獨立 12–256 字元密碼，配合 AES-256-GCM、有界限 scrypt、隨機鹽及 IV，將秘密、參數、標籤同群組密封。只有嚴格密文封套傳到原生選擇新檔案儲存器；密碼同明文備份唔會進普通匯出或版本記錄。遺失密碼就無法還原備份。呢個面板暫時未提供備份匯入；受保護解碼只係原生輔助，唔係介面秘密顯示 API。

每個原生操作會重新檢查固定安全目的地及操作鎖。建立審閱保留一次性解鎖，嘗試修改／儲存先消耗。鎖定時仍可撤銷審閱。寫入使用原有系統憑證庫加密及原子替換，無明文備用路線。修改回呼只含已清理資料。獨立受密碼保護加密修改歷史仍屬下一批整合，普通管理歷史唔係嗰個服務。

原生測試用獨立加密憑證庫，同實際本地 PNG→jsQR 解碼，覆蓋重新啟動、編輯、群組、排序、批次範圍、匯出排除、確認、過期及受保護備份驗證。打包 Material 控制測試覆蓋手動註冊、標籤／群組、取消及完整刪除，同三種語言。現有 RFC 6238 向量驗證三個演算法。呢啲唔代表 Windows 憑證庫／安裝、真實相機權限或外部帳戶接受已驗證。
