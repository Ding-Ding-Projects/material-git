# 工作區、分頁同記錄

Material Git 會喺呢部裝置保存分頁次序、固定狀態、群組、收起狀態、停泊方向、面板尺寸、分割畫面同指令選單大小。分頁列預設喺左邊；管理器可以改到右、上或下。指令輸入草稿只留喺記憶體，唔會放入匯出檔案或本機 Git 記錄。

開啟功能頁面後，可以拖動分頁排序，或者用 Alt+Shift+方向鍵。Ctrl+Shift+P 固定或取消固定分頁；方向鍵會跟隨分頁列方向，Home 同 End 跳到兩端。管理器有每頁十個結果嘅完整清單，而且分頁列、全部分頁、群組名稱同群組內分頁各自有獨立搜尋同正則表達式工具。

群組可以建立、改名、改顏色、排序、固定同收起。移動到群組會開啟可搜尋嘅選擇器；刪除群組會保留分頁。批次關閉預設保護固定分頁，會先顯示受影響標題。已修改輸入要先確認放棄，進行中操作則繼續。程式關閉同重新啟動會繼續檢查 API 同 CLI 設定嘅未完成工作。

分割畫面會喺目前工作旁邊開啟獨立嘅離線文件瀏覽器，分隔線支援拖動同鍵盤。Ctrl+Shift+F 開啟指令選單，可以尋找目的地、設定、文章同目前頁面控制項，並直接操作設定。

通知中心最多保留五百項已清理記錄，重新啟動後仍然存在。可以標記已讀或未讀、暫時隱藏、還原同匯出。詳細錯誤只喺目前工作階段顯示，永久記錄唔會保存服務供應者輸出。Shift+點擊或 Shift+空白鍵可以選取範圍；選取本頁同選取全部相符項目有清楚範圍。

工作區歷史喺程式資料目錄內嘅獨立 Git 儲存庫保存完整已驗證資料，唔會修改你自己嘅儲存庫。文字、日期同操作篩選可以一齊用。比較會顯示改變欄位；還原會新增版本，唔會改寫舊記錄。Git 記錄失敗唔會阻止原本操作，介面會清楚提示。

匯出同匯入使用版本一 `material-git-records` UTF-8 JSON 格式。工作區同通知可以先驗證、完整預覽再匯入；未知欄位、憑證字串、重複識別碼同缺少群組會令整份檔案被拒絕。歷史匯出只供查閱。匯入工作區唔會清除目前記憶體草稿。

全部 Markdown 文章都會喺建置時包入程式，離線照樣可用。文章連結留喺程式內。關於頁面會顯示目前名稱、版本同實際建置時間；資料缺少會如實顯示。
