# 記錄、版本同活動

版本工作區合併已驗證工作區快照，同原生服務已記錄嘅設定、排程、外觀等受管理版本。獨立本地 Git 儲存庫屬於應用程式資料，唔會改用戶儲存庫。標籤同版本保留數量使用原生記錄 API。比較受管理版本要有相同來源種類同記錄身分，會顯示已清理完整欄位差異。瀏覽、比較同匯出唔會還原記錄。

文字同完整正則搜尋，可同包括首尾日嘅本地日期、實際操作及來源篩選一齊使用。數量取自原生服務傳回嘅記錄。日期欄旁邊嘅有限日曆支援可搜尋月份、年份跳轉、日期範圍、方向鍵同預設期間。本地日期或 `YYYY-MM-DD` 都接受；未完成、無效或倒轉範圍會保留輸入，繼續使用上一個有效篩選。每個集合及選項清單有獨立搜尋及旁邊完整正則建立器。

每頁二十行；選擇本頁會保留其他頁選擇。可選所有符合記錄、反選、清除、Shift 點選及 Shift+Space 範圍。隱藏選擇保留，但唔包括喺目前篩選操作或匯出；如果選擇全部隱藏，唔會意外匯出所有記錄。格式由實際資料決定：記錄陣列支援 JSON、JSONL、YAML、XML、CSV、TSV、HTML、SQL 文字、Markdown 同純文字；其他結構只顯示合適格式。儲存前會顯示序列化限制。完整可匯入備份固定使用第 1 版 JSON 封套，唔受表格格式選擇影響。

還原工作區、設定或排程，要審閱確實快照、兩個確認同滑動確認。原生服務再驗證記錄，並新增版本。其他受管理種類喺呢個面板只供審核，唔聲稱可以還原憑證、安全記錄或提供者狀態。工作區及受管理版本清理分開審閱，顯示實際保留及刪除數量。匯入先驗證完整本地 JSON 封套，再審閱取代範圍；表格及受管理版本匯出唔可匯入。

活動工作區支援指令、狀態及工作階段輸出正則搜尋、本地日期、狀態篩選、分頁及範圍選擇。操作資料匯出唔包括輸入、憑證或輸出；可喺詳細頁另行匯出可見標準或錯誤輸出。已截斷輸出會清楚標示。取消審阅只送出仍執行中嘅所屬操作 ID，略過審閱期間已完成工作，等原生狀態更新。已開始嘅遠端或檔案變更可能保留。

原生記錄要求會報告忙碌狀態；未儲存匯入、標籤及破壞性審閱，會報告所屬工作區草稿。應用程式要遵守現有離開保護，原生放棄記錄成功後先呼叫 `discardDrafts()`。寫入失敗保留草稿，顯示原生錯誤。

驗證使用實際打包 Material 控制同獨立原生 `WorkspaceStore`，測試選擇、CSV 匯出、日期、標籤、比較、新增式還原、取消範圍、輸入排除及雙語可讀名稱。測試唔代表提供者權限、平台安全儲存或 Windows 安裝已驗證。
