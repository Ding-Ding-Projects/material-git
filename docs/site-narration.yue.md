# 網站事實語音讀出

網站讀出預設關閉。偏好設定同「搜尋所有內容」（`Ctrl+Shift+F`）提供讀出語言、英文同香港廣東話聲線、速度、音調、暫停語音，同配合螢幕閱讀器。呢啲係可以直接操作嘅 Material 控制項，會儲存喺瀏覽器本機偏好設定同記錄。

網站有獨立嘅共用事件讀出器實例。每個事件保留種類，同獨立英文、廣東話事實，直到產生讀出文字。普通種類延遲 180 ms，同有 4 秒冷卻時間。同種類排隊中文字會由最新事件取代。錯誤唔受呢兩個限制，保留先入先出次序。每次只讀一句；雙語會讀完英文，再讀廣東話。趣味程度只改語氣，唔改錯誤同恢復事實。

聲線選項來自瀏覽器真正提供嘅語音列表，用穩定 `voiceURI` 識別碼儲存。「自動選擇」係預設，優先用已安裝本機聲線。稍後嘅 `voiceschanged` 事件會更新列表。每個選項下方顯示實際聲線、未能使用嘅已儲存選擇同保留識別碼及替代聲線、冇合適聲線，同離線時不可用嘅網絡聲線。廣東話需要香港地區聲線，唔會用普通話代替。冇聲線時仍然保留文字事實。

瀏覽器無法可靠偵測螢幕閱讀器。**配合螢幕閱讀器**係由你明確選擇並持續儲存嘅設定，會取消讀出。**暫停語音**獨立暫停聲音，同取消排隊句子。文字訊息繼續顯示。關閉讀出器或移除網站元件亦會取消同釋放實例。網站唔會聲稱可以控制作業系統語音服務。

偏好設定驗證、本機儲存失敗、詞彙同外觀驗證、顯示解鎖錯誤、時間表同外部來源失敗，以及版本檢查，都會報告真正失敗情況，並喺適用時講明下一步。錯誤同警告會保留至關閉，或者下一個訊息取代。持續訊息集合仍然未完成。

訪客狀態 JSON 匯出目前用版本 2：包括偏好設定、已驗證時間表、導覽、外觀、顯示，同時間提示記錄。仍然接受版本 1 偏好設定匯入。版本 2 還原會使用原有顯示解鎖保護，同加入記錄快照；唔會匯入憑證、上載標誌圖片資料或個人詞彙映射。其他通用匯出格式仍然未完成。

檢查會分清真實瀏覽器控制項同聲線可用狀態，以及用嚟驗證順序、種類、失敗事實同稍後聲線列表嘅受控語音替代介面。替代介面結果唔代表已驗證真正平台聲線、聲音質素，或螢幕閱讀器偵測。
