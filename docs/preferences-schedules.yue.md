# 排程設定同已批准來源

設定有一般、外觀、聲音同朗讀、專注設定、個人用語同排程設定分頁。搜尋會跨分頁；每項設定都有解釋、實際內置預設值或已儲存記錄來源，以及獨立重設。應用程式顯示名稱唔會更改套件識別、資料位置、更新來源或診斷識別。

排程使用版本 1、IANA 時區，以及最多 64 個規則，文件上限 256 KiB。每條規則有穩定識別碼、名稱、啟用狀態、整數優先次序、可選日期範圍、開始同結束本地時間、星期同已驗證設定。每日只需一條包含七日嘅規則。包括開始時間，唔包括結束時間；相同時間代表全日。跨午夜時段按開始日期同星期計算。夏令時間重複時段會符合兩次，跳過時段唔會出現。較高優先次序優先；相同次序按識別碼字元編碼排序。覆寫結束後，原本本機基礎設定會重新生效。

引導編輯器可以選擇任何已儲存設定，亦可以將元素目前已儲存外觀存入排程。本機規則直接套用數值。HTTPS 規則讀取 `{ "schemaVersion": 1, "settings": { "theme": "dark" } }`，亦可以包含按穩定元素識別碼排列嘅 `appearance`。Home Assistant 使用 `binary_sensor` 或 `input_boolean`；`on` 套用本機規則數值，`off` 交畀其他符合規則或基礎設定。未知狀態唔會套用。

來源必須先喺連線介面批准。正式路線只接受 HTTPS、公眾 DNS 名稱、標準 TLS 連接埠，以及冇內嵌憑證或片段嘅網址。主程序拒絕私人或保留 DNS 位址，將已驗證位址固定喺 TLS 請求，拒絕重新導向，只接受 JSON。請求全部係唯讀 GET。啟用時會更新，之後按 30 至 3600 秒間隔更新。回應上限 64 KiB 同八秒；重複或不安全 JSON 鍵會被拒絕，舊請求亦唔可以覆寫新設定。失敗或離線會回復本機基礎設定並提供恢復提示，遠端回應唔會變成永久設定。

存取權杖透過作業系統憑證設施加密，按穩定連線識別碼儲存。介面只顯示有冇憑證，唔會傳返權杖或寫入規則、匯出或歷史。系統無法提供受保護儲存時，會拒絕儲存。匯出唔包括個人用語內容、檔案資料同來源憑證。匯入來源必須符合已批准連線；匯入檔案唔會自動批准新網絡地址。

JSON 匯入會先驗證整份文件。基礎設定、排程同元素樣式一齊匯出；寫入失敗時會透過已驗證 API 恢復原本數值。程序喺多個寫入之間突然關閉，唔屬於跨檔案交易；有需要可以檢查本機歷史再匯入之前嘅匯出。

專注測試包括 `tests/preferences-advanced.test.ts` 同 `tests/settings-inventory.test.ts`。`node tests/preferences.browser.mjs` 使用臨時資料設定，操作真實桌面控制同本機儲存，並喺輸出目錄儲存畫面同無資料負載收據。外部來源使用可預測傳輸測試，唔代表已驗證真實 Home Assistant 安裝。
