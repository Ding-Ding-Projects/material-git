# 元素外觀同可攜主題

透過元素外觀動作編輯穩定設計識別碼。支援正常、滑過、焦點、按下、選取、停用、拖曳、驗證、載入、成功、警告同錯誤狀態。正常數值透過 CSS 繼承，其他狀態保留独立覆寫。排程外觀覆蓋本機基礎，但唔會更改基礎快取；樣式會安裝喺元素真實文件或 shadow root，唔會略過巢狀元件。

字體功能有字體、自由輸入大小同滑桿、粗幼、樣式、底線／刪除線、字距、行高同對齊。已安裝字體由原生清單提供，缺少時會誠實使用系統替代。顏色可以輸入十六進位、RGB、HSL，亦有顏色盤、最近顏色同文字背景對比。對比讀數明確假設不透明顏色，唔會聲稱驗證任意圖片背景或透明合成。

每個狀態最多 32 個已命名可排序圖層，支援群組、顯示、編輯鎖、複製、改名、排序同重設。CSS 合成支援純色、圖片、線性／放射／圓錐漸層、條紋、圓點、棋盤、混合模式、邊框、外框、多重陰影、光暈、濾鏡同背景模糊。幾何有大小、間距、圓角、旋轉、移動、縮放、傾斜、透視同變形原點。矩形、橢圓同 SVG 路徑裁剪都保留原本內容。本機 PNG／JPEG／WebP 會解碼並轉換成有界限 PNG；唔接受 SVG、動畫或外部圖片網址。

可搜尋屬性檢查器使用應用程式 regex 建構器。提供屬性、圖層、狀態、元素同全域重設，復原／重做，本機複製貼上樣式，命名主題同 JSON 匯入匯出。每次儲存都有大小有限本機歷史；匯出版本 2，亦接受版本 1 元素匯出。快取會整體驗證，未知欄位或不安全 CSS 會拒絕，無效匯入唔會更改設定。全域重設清除本機元素外觀；排程覆寫要停用相關規則先會消失。

能力說明會列明平台限制：像素色版、畫筆、徒手取樣、網格扭曲同智慧物件需要點陣／向量文件引擎，目前唔會實作或聲稱已具備。編輯器操作 DOM CSS；群組係整理標籤，唔係巢狀點陣文件。呢個係真實可復原 CSS 編輯器，唔代表 Photoshop 點陣功能對等。

測試包括全部十二狀態、数值限制、重複圖層識別碼、拒絕遠端／SVG、路徑注入同對比。`node tests/preferences.browser.mjs` 亦操作真實已建置桌面字體套用、復原／重做、圖層改名、本機樣式複製貼上同窄畫面。唔代表所有屬性逐次畫面證據或 Windows 視覺對等認證。
