# 元素外觀同可攜主題

透過元素外觀動作編輯穩定設計識別碼。支援正常、滑過、焦點、按下、選取、停用、拖曳、驗證、載入、成功、警告同錯誤狀態。正常數值透過 CSS 繼承，其他狀態保留独立覆寫。排程外觀覆蓋本機基礎，但唔會更改基礎快取；樣式會安裝喺元素真實文件或 shadow root，唔會略過巢狀元件。

字體功能有字體、自由輸入大小同滑桿、粗幼、樣式、底線／刪除線、字距、行高同對齊。已安裝字體由原生清單提供，缺少時會誠實使用系統替代。顏色可以輸入十六進位、RGB、HSL，亦有顏色盤、最近顏色同文字背景對比。對比讀數明確假設不透明顏色，唔會聲稱驗證任意圖片背景或透明合成。

每個狀態最多 32 個已命名可排序圖層，支援群組、顯示、編輯鎖、複製、改名、排序同重設。CSS 合成支援純色、圖片、線性／放射／圓錐漸層、條紋、圓點、棋盤、混合模式、邊框、外框、多重陰影、光暈、濾鏡同背景模糊。幾何有大小、間距、圓角、旋轉、移動、縮放、傾斜、透視同變形原點。矩形、橢圓同 SVG 路徑裁剪都保留原本內容。本機 PNG／JPEG／WebP 會解碼並轉換成有界限 PNG；唔接受 SVG、動畫或外部圖片網址。

可搜尋屬性檢查器使用應用程式 regex 建構器。提供屬性、圖層、狀態、元素同全域重設，復原／重做，本機複製貼上樣式，命名主題同 JSON 匯入匯出。每次儲存都有大小有限本機歷史；匯出版本 2，亦接受版本 1 元素匯出。快取會整體驗證，未知欄位或不安全 CSS 會拒絕，無效匯入唔會更改設定。全域重設清除本機元素外觀；排程覆寫要停用相關規則先會消失。

能力說明會列明平台限制：像素色版、畫筆、徒手取樣、網格扭曲同智慧物件需要點陣／向量文件引擎，目前唔會實作或聲稱已具備。編輯器操作 DOM CSS；群組係整理標籤，唔係巢狀點陣文件。呢個係真實可復原 CSS 編輯器，唔代表 Photoshop 點陣功能對等。

測試包括全部十二狀態、数值限制、重複圖層識別碼、拒絕遠端／SVG、路徑注入同對比。`node tests/preferences.browser.mjs` 亦操作真實已建置桌面字體套用、復原／重做、圖層改名、本機樣式複製貼上同窄畫面。唔代表所有屬性逐次畫面證據或 Windows 視覺對等認證。

## 非模態入口同文字控制

應用程式可安裝 `installAppearanceRoutes`。按 `Ctrl+Alt+A` 編輯目前焦點元素；右鍵提供「編輯外觀」，Shift 加右鍵直接開啟。已有分頁選單會保留管理功能，再按元素識別碼開啟外觀。面板唔會鎖住其他內容，會跟隨元素位置，關閉後交還焦點；面板入面嘅控制亦可再開外觀編輯。

有明確設計識別碼嘅元素優先使用原有識別。其他控制使用跨開放 shadow root 嘅結構位置，唔包含文字、輸入值、供應商名稱或檔案路徑。無穩定識別碼嘅清單重新排序後，樣式仍可能跟隨位置；逐筆記錄嘅持久識別仍未完成。

文字、色彩、幾何同效果分頁分開屬性。新增字詞間距、縮排、基線偏移、上標下標、小型大寫、數字形式、字偶間距、方向、大小寫、頂線、雙線或波浪線、裝飾線顏色粗幼偏移、文字輪廓、陰影同底色。可變字體軸接受經驗證嘅四字元標籤同數值；只有字體本身提供嘅軸先有效，未聲稱能列出所有軸。字體搜尋有獨立正則表達式工具，字體名稱用自己嘅字款顯示。

## 連續色彩轉換

色彩編輯器提供連續飽和度及亮度平面、可用鍵盤輸入嘅數值、色相同透明度，以及 HEX/HEX8、CSS 顏色名稱、RGB、HSL、HSV/HSB、HWB、D50 CIELAB/LCH、D65 OKLab/OKLCH 同數學 CMYK 轉換。CMYK 無打印機 ICC 色彩描述檔，唔代表打印色準。複製會保留所選表達方式同透明度。對比度會先合成透明色，透明背景後方按白色計算。

超出 sRGB 會先警告，未確認前唔改已儲存樣式。按「套用裁切後 sRGB」先套用，取消就保留原值。儲存模型仍然係 sRGB，唔係廣色域文件引擎。

## 實作同證據界線

文字及色彩資料沿用狀態、圖層、復原、歷史、匯入匯出驗證。數學測試涵蓋九個色彩空間往返、透明度、超色域同錯誤輸入。Electron 元件測試使用清楚標明嘅本機測試頁及字體橋接，驗證真實滑鼠鍵盤、焦點交還同窄畫面；唔代表正式應用整合、供應商權限、Windows 安裝或原生字體列舉。測試圖唔可放入產品相簿。

光柵通道、筆刷、自由選取、顏色範圍選取、智慧物件、網格扭曲、尺規輔助線同完整文件合成器仍未提供。可變字體軸列舉、每項屬性完整翻譯同平台驗證亦未完成。`appearance-change` 提供版本、元素識別、已驗證記錄同時間，原生 Git 歷史整合由主程式負責；未聲稱已達完整 Word 或 Photoshop 功能。

## 流動彩虹

前景、背景同邊框可喺同一色彩編輯器選擇「流動彩虹」。佢係獨立模式標記，唔係十六進制顏色字串，亦唔會混入色板。原本固定顏色會保留，轉返固定模式就還原；彩虹用完整飽和度同 50% 亮度，保留透明度。

全應用程式共用一個本機速度級別，1 至 5 分別每圈 32、16、8、4、2 秒。文件根元素透過 CSS 自訂屬性轉色，所有彩虹元素同 shadow root 控制繼承同一時間，無逐幀 renderer 回呼。系統減少動態或應用程式關閉動畫時，固定喺色相 270。無效快取回復第 3 級，超範圍寫入會拒絕。

數學測試覆蓋模式、速度驗證同減少動態規則。已編譯 Electron 測試頁驗證實際轉色，再模擬減少動態，確認顏色固定。全域速度仍係本機設定；外觀記錄匯出包含元素模式，暫時唔包含呢個全域速度。

## 非破壞式 PNG 裁剪同變換

現有本機 PNG 填色可用原圖像素設定裁剪範圍、順時針四分一圈旋轉，同水平或垂直翻轉。預覽由保留嘅原圖生成；按「套用圖片變換」先將新 PNG、原圖同數值配方儲存到所選狀態或圖層。重複編輯唔會反覆重取樣上次輸出。復原、切換圖層同匯入會重新載入配方；重設預覽未按套用前唔改目前填色。

解碼前驗證 PNG 簽名、區塊長度、標頭、圖像資料同結束標記。原始編碼最多 36 KiB，data URL 最多 48 KiB，尺寸最多 512 × 512，像素最多 262,144。動畫同壓縮附加資料會拒絕。Chromium 解碼尺寸必須同標頭一致，輸出亦再次驗證。失敗會保留原圖同目前填色。現有圖片匯入器只產生最長邊 128 像素嘅顯示填色；呢啲工具唔會恢復已縮細嘅細節，亦唔改來源檔案。

Electron 像素測試實際操作 Material 裁剪、旋轉同翻轉控制，解碼輸出 PNG，核對尺寸同 RGBA 像素。呢個係清楚標明嘅元件測試頁，唔係真實文件或公開產品相簿證據。筆刷、通道、自由或顏色範圍選取、進階向量布林運算、智慧物件同扭曲仍未實作。

主程式及搜尋選單可呼叫 `mg-appearance.focusProperty(state, field)`。佢會驗證狀態、清除屬性搜尋、切換真正分類、等待繪製，再聚焦確切嘅 Material 控制。控制不存在或停用會回傳 `false`，例如無圖片時嘅裁剪控制。

## 有界向量合成

每個外觀狀態或圖層可保留有版本嘅向量文件同衍生 PNG 填色。「向量形狀同路徑」提供真正畫布預覽，同矩形、橢圓、三角形及三次曲線預設；橢圓由四段三次曲線組成。形狀可改名、顯示或隱藏、鎖定、排序、複製、刪除，亦可調整填色、描邊顏色粗幼接合、透明度同六種合成方式。支援 source-over、multiply、screen、overlay、darken、lighten，以及 nonzero、evenodd 填色規則。

藍色控制點移動端點，橙色控制點調整 Bézier 曲線。可拖曳，或聚焦後用方向鍵；Shift 將步幅由一個原圖像素改為十個。數值欄提供同樣操作。路徑支援 M/L/Q/C/Z 移動、直線、二次曲線、三次曲線、閉合，以及加入、刪除同線段轉換。二次轉三次曲線係精確升階；三次轉二次係近似值，曲線轉直線會移除控制點，介面會說明並保留復原。

預覽由 canvas 合成器繪製。套用會提交已驗證向量來源及 PNG，將光柵裁剪配方重設到新來源。原有外觀復原及歷史保留上次已套用記錄。未套用向量修改有獨立三十步復原重做；切換狀態或圖層會保留仍開啟嘅預覽。關閉時有放棄確認，開啟巢狀外觀編輯器亦唔會清除父編輯器嘅未儲存狀態。預覽未按套用前唔會持久儲存，亦唔會混入其他情境嘅匯出。

限制包括畫布 16 至 512 像素、最多 16 個形狀、每個形狀 128 個指令、合共 512 個指令、32 KiB JSON，座標只接受 -1024 至 1024 嘅有限數值，並沿用 PNG 填色限制。只接受有版本嘅向量 JSON；SVG 標記、程式碼、外部網址、未知欄位或指令、重複識別同超限幾何資料會拒絕。SVG 由數值幾何同允許嘅填色重新生成，形狀名稱唔會放入標記。匯出圖片係靜態，嵌入色彩選擇器會停用彩虹並說明原因；外層介面圖層仍有獨立流動色彩模式。

JSON 使用原有匯出流程。有原生 `exportAppearance` 橋接嘅版本亦可透過原生儲存對話框匯出 SVG/PNG；無橋接時會明確顯示不可用。原生層驗證文件、重新生成 SVG，同驗證及重新編碼 PNG，但唔會獨立繪製文件以證明 PNG 同來源完全對應。Renderer 測試會另外核對所用測試資料嘅對應。

Electron 測試頁實際拖曳端點、用鍵盤移動曲線控制點、復原、保留跨狀態預覽、確認放棄、核對巢狀未儲存防護、操作合成方式同核對匯出 SVG/PNG 像素。寫檔橋接只係隔離測試，唔代表正式原生儲存對話框已驗證。圓弧、手繪描圖、路徑布林運算、文字轉輪廓、網格扭曲、光柵筆刷、通道同完整 Photoshop 功能仍未提供。

### 整合交接

共用模組匯出 `validateVector`、`vectorSvg`、`vectorPath`、`vectorPreset` 同 `convertVectorCommand`。外觀路由會整合所有巢狀編輯器嘅 `appearance-work-state`，資料係 `{id: "appearance", busy, dirty}`；應用程式要將呢個狀態加入現有關閉同更新保護。錨定編輯器負責確認放棄預覽，已儲存記錄繼續使用 `appearance-change` 歷程整合。`focusProperty(state, "vector")` 會聚焦實際向量控制。

呢個檢查點通過 TypeScript、18 項外觀來源測試、14 項向量 Electron 測試樣本檢查，同 15 項現有外觀 Electron 測試樣本檢查。範圍限於上文有界流程，唔代表所有屬性、所有平台或可選原生匯出橋接已驗證。填色同描邊先合併，再套用一次形狀透明度，重疊邊緣同 SVG 顯示一致。
