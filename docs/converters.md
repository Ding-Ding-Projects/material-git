# Local converters

Utilities mounts the registered `mg-converters` Material composition. Category and operation pickers select genuine local conversion logic; input and output are labelled, output remains selectable and read-only, clipboard failures leave it available to copy manually, and invalid conversions clear stale output and show the error at the surface. The component has its own appearance colour sliders and an adjacent regex builder for the named-time-zone search. English, Hong Kong Cantonese and bilingual labels are supported.

Text operations encode/decode a URL **component**, encode UTF-8 text to standard padded Base64, decode Base64 to strictly valid UTF-8, and format or compact JSON. Base64 padding bits are validated. Base64 and URL encoding are not encryption. JSON uses JavaScript parsing and number precision; it does not preserve duplicate keys, number spelling or arbitrary-precision integers. Conversions accept at most 1 MiB of UTF-8 input. They never run a shell command or contact a remote service.

Colour operations translate three/four/six/eight-digit hex, numeric RGB channels with optional 0–1 alpha, and HSL with 0–360-degree hue and 0–100-percent saturation/lightness. RGB/HSL functional syntax or plain channel tuples are accepted; the selected format must match a provided function wrapper. Hex alpha is quantized to one byte. Sliders provide live HSL/alpha conversion; they replace the text input with the represented HSL value rather than altering an unrelated stored theme.

Time operations convert Unix seconds, Unix milliseconds and ISO 8601 with required seconds and an explicit `Z` or UTC offset. Invalid calendar dates and timestamps outside JavaScript's supported Date range are rejected. The output can be ISO UTC, Unix time or a named IANA zone with the zone label displayed. Zone choices come from the runtime's actual `Intl.supportedValuesOf('timeZone')` enumeration plus UTC. Fractional milliseconds follow JavaScript Date millisecond resolution. Local ambiguous wall times, leap seconds, natural-language dates and time-zone database installation are not supported.

Length and mass use exact declared scalar factors; temperature converts Celsius, Fahrenheit and Kelvin while rejecting values below absolute zero. Storage explicitly separates decimal KB/MB/GB/TB from binary KiB/MiB/GiB/TiB and supports bytes and bits. Unit results use twelve significant digits and JavaScript floating-point arithmetic. Negative scalar length/mass/storage values are permitted as mathematical quantities; the tool does not infer physical validity beyond absolute-zero checks. Currency, remote rates, documents, images, archives, multimedia, arbitrary file formats and batch file processing are not implemented by this bounded converter component.

Tests exercise actual exported conversion functions: Unicode round trips, malformed URL/Base64/JSON, padding bits, colour channels and alpha, offsets and invalid calendar dates, time zones, SI versus IEC factors, temperature boundaries and numeric overflow. They do not establish built-artifact interactive, keyboard, screen-reader or capture evidence.
