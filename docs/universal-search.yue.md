# 通用搜尋

Ctrl+Shift+F 會開啟有限卡片或全視窗搜尋。註冊表包含所有基本設定、巢狀排程設定、安全控制、本地詞彙控制、原生 GitHub 情境操作、指令規格、離線文件，同穩定工作區元素外觀全部十二種狀態嘅屬性。未開啟相應頁面之前，呢啲結果已經存在。已儲存排程規則來自原生設定狀態；私人存取憑證同圖片內容唔會加入搜尋。

基本設定結果包含實際開關、有界限滑桿同數值欄位、可搜尋選項、顏色控制，同實際已安裝語言聲音選項。佢哋使用原有設定驗證器同原生設定介面，所以儲存同受管理版本記錄會同原有設定頁一致。字體選項來自原生字體清單。已儲存但缺失嘅聲音會保留選擇，唔會默默取代。自訂圖片結果會開啟所屬上載控制，並解釋圖片轉換需要完整編輯器。

每個選項彈出框都有獨立文字搜尋同旁邊完整正則表達式編輯器。篩選唔會取代已選數值。搜尋結果選擇清楚區分本頁、全部符合結果同反選範圍；跨頁保留選擇，支援 Shift 範圍，分開顯示符合及隱藏選擇數量。只有目前結果頁會建立行內控制。

選擇其他頁面嘅結果時，應用程式會先開啟所屬工作區，再呼叫 `focusDiscoveryResult`。設定會開啟相應隱藏分頁；排程結果會選擇已儲存規則。情境工作交接使用原有工作區嘅忙碌同草稿保護，只顯示可審閱表格，唔會提交或自動讀取工作。外觀結果會開啟元素旁邊編輯器，聚焦相應狀態同屬性。無法使用或被拒絕嘅目標會由應用程式報告，唔會默默改變其他工作。未有已註冊情境控制嘅指令會清楚說明限制，開啟文件而唔係執行通用指令。

整合會將實際呈現模式同原生設定狀態傳入搜尋。共享呈現模式啟用時，隱藏語言、詞彙同幽默功能，以及相關文件都唔會出現。安全結果使用使用者選擇嘅模式名稱，唔會洩露內置名稱。

驗證：`tests/workspace-discovery-render.test.ts` 會運行已打包註冊 Material 控制，檢查其他頁面結果覆蓋、改變實際設定滑桿、拒絕無效數值更新，並聚焦隱藏排程分頁嘅時區欄位。呢啲係固定測試資料行為；即時提供者權限同平台字體／聲音供應繼續以原生執行狀態為準。
