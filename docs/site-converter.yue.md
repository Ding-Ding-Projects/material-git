# 網站本機檔案轉換工具

訪客偏好設定同「搜尋所有內容」（`Ctrl+Shift+F`）可以開啟網站獨立轉換工具。轉換工作空間喺轉換網站部分時會留喺呢個瀏覽器，唔會存取桌面檔案權限、引擎或佇列。所選檔案唔會上傳，亦唔會發出網絡轉換請求。

分類目錄包括結構資料／試算表、圖片、文件／PDF、音訊、影片、封存、程式碼／文字同二進制編碼。每個不可用工具都保留停用項目，解釋實際缺少嘅瀏覽器實作或引擎。已啟用目的格式支援 UTF-8 JSON、JSONL、YAML、Material Git 型別 JSON XML 結構、CSV 同 TSV，或者經檢查嘅 PNG／JPEG／WebP 圖片。結構來源按數值結構使用共用序列化工具，輸出 JSON、JSONL、YAML、型別 XML、CSV、TSV、HTML、SQL、Markdown 同純文字。呢度唔會轉換任意原始碼、Office 文件或一般 XML 文件。

准入逐一處理瀏覽器 FileList，每個檔案最多讀取 128 KiB 標頭。圖片簽章優先於名稱；結構文字只係候選格式，之後由隔離背景工具驗證完整而有資源限制嘅來源。唔支援、空白同超出配額嘅來源會略過，並報告實際准入／略過數量。唔會複製檔案陣列，亦唔會一齊載入所有檔案位元組。每個來源／輸出最多 8 MiB、保留來源總共 64 MiB、保留結果總共 32 MiB、佇列中繼資料 1 MiB。冇檔案數量配額。名稱最多 1,024 個字元。瀏覽器選擇器仍然提供 FileList，唔係原生分頁資料夾權限。

每個工作擁有自己嘅目的格式。如果選咗文字目的格式，新圖片預設轉成 PNG；如果選咗圖片目的格式，結構来源預設轉成 JSON。目錄、佇列同收據記錄各自擁有文字搜尋同旁邊嘅正則搜尋工具。表達式喺背景工具執行，格式最多 256 個字元，總限時 200 ms。種類同工作狀態會同搜尋一齊篩選。工作同收據事實每頁 20 個。工作選擇支援 Material 選擇框、Shift 點擊／Shift+Space 範圍、呢頁／所有符合、反轉同清除。篩選以外嘅已選工作會計數，而且唔會處理。

轉換首先檢閱確實已選而合資格嘅工作同目的格式。修改目的格式或佇列會令檢閱失效。檢閱會說明格式／註解／結構改變、CSV／TSV 型別損失同公式保護、SQL 只輸出文字唔執行，以及圖片中繼資料／色彩描述／EXIF 移除、動畫壓平、JPEG／WebP 90% 品質同 JPEG 白色透明背景。來源保持不變。已檢閱目的格式會喺佇列執行期間鎖定。失敗同已取消工作可以重新檢閱。

一次只執行一個專用背景工具，限時 15 秒，取消時會終止。結構資料會拒絕唔安全整數、保留鍵、唔支援 YAML 標籤／別名、無效型別 XML 同格式錯誤嘅分隔記錄。共用數值驗證最多 100 層同 100,000 個數值。JSON／YAML／型別 XML／JSONL 輸出會重新開啟並比較數值；CSV／TSV 會重新開啟成一致資料表。其他文字輸出使用共用有資源限制嘅序列化工具。圖片喺瀏覽器解碼前先檢查尺寸：每邊最多 4,096 像素，總共 8,388,608 像素。已編碼圖片會重新開啟驗證尺寸。瀏覽器編碼器不可用時會如實失敗。背景工具限時限制 JavaScript 執行，唔係瀏覽器解碼程序作業系統隔離嘅證明。

暫停喺下一個檔案之前生效，目前背景工具會完成。繼續只處理已檢閱工作集合。取消同移除會檢閱確實符合篩選嘅選擇；取消會終止執行中背景工具，移除會釋放已選記憶體來源／結果。已完成收據事實保持不變。下載將已驗證位元組交畀瀏覽器下載管理器。網站無法驗證磁碟寫入、以原子方式發佈目的資料夾、偵測覆寫決定或繞過瀏覽器下載權限。

最後 200 個已刪除敏感資料嘅結果收據會持續保留，只包含識別碼、時間、來源／目的格式、位元組數量同結果。名稱、路徑、內容同輸出位元組唔會加入儲存、普通訊息記錄同收據匯出。每個背景工具開始之前會儲存中斷標記。重新載入會失去檔案權限同輸出位元組，所以中斷工作會明確要求重新選擇來源，唔會聲稱已崩潰復原。收據事實會加入第 2 版訪客轉移同訪客記錄快照；還原收據唔會重做轉換或還原檔案。收據搜尋決定實際 JSON 匯出範圍。

Office／PDF 操作、FFmpeg 音訊／影片、封存解壓、二進制編碼器、原生資料夾發佈、持續來源權限同崩潰後自動繼續仍然不可用。呢個係部分瀏覽器功能，唔係完整轉換要求已完成。檢查使用實際本機樣本轉換同已下載輸出、解析／尺寸反例、已檢閱效果、獨立搜尋、持續儲存同真實窄視窗 Chromium 擷取。200% 文字導覽標籤重疊已另外排隊處理。
