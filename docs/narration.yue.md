# 事件朗讀同訊息風格

朗讀預設關閉。喺聲音同朗讀分頁啟用後，可以選英文、香港廣東話或雙語。雙語先讀英文再讀廣東話，每次一句，唔會重疊。兩種語言各有已安裝聲音選擇器；預設自動選擇。應用程式儲存穩定聲音 URI，唔係顯示名稱。遲到嘅聲音列表會自動更新；已移除聲音會保留選擇並使用替代，網絡聲音會標明，缺少語言聲音亦會報告。唔會用普通話代替廣東話。語速範圍 0.5 至 2，聲調 0 至 2，正常都係 1。

一般事件會等 180 毫秒消除重複，取代同類別排隊事件，完成後有四秒冷卻。錯誤略過時間限制；`announceMessage` 保留精確事實，只調整周邊語氣。語音回呼令雙語依次播放；取消會清空排隊語音並令舊回呼失效。螢幕閱讀器或安靜聲音設定會即時暫停應用程式朗讀。瀏覽器無法可靠偵測螢幕閱讀器，所以需要明確設定，唔會聲稱自動偵測。

英文同廣東話各有獨立已儲存趣味程度，1 最認真，5 最有趣，預設都係 5。狀態、錯誤、警告、破壞性操作、金錢、安全、無障礙同進度訊息都適用，但事實保持原樣。對話框表情係獨立、冇語義嘅裝飾，唔會加喺控制標籤或無障礙名稱。`languageParts` 提供主要同較細副語言文字；有空間嘅表面可以使用合併 `t`。

應用程式文字放喺獨立 `localization-resources.ts`。`t` 使用資源識別碼；`localizeText` 只翻譯已登記、應用程式自己寫嘅精確文字。指令、供應者記錄、聲音名稱、網址、路徑、識別碼同外部事實保持原文。個人用語只套用已登記應用程式文字、只留本機、唔會匯出或寫入歷史。缺少資源時會保留識別碼，唔會虛構翻譯。

`tests/preferences.test.ts` 驗證語言程度、所有訊息類別事實、聲音識別同替代、雙語順序、排隊取代、冷卻同螢幕閱讀器取消。真實聲音由系統已安裝語音決定；模擬語音測試唔代表已驗證 Windows 聲音播放。
