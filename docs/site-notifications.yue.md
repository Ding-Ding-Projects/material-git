# 網站訊息中心

網站有獨立瀏覽器本機訊息集合，同桌面記錄分開。可以喺偏好設定同「搜尋所有內容」（`Ctrl+Shift+F`）開啟訊息中心。角落最多顯示三個近期適用訊息，卡片唔會重疊，較舊訊息仍然留喺中心。角落集合限制喺視窗內，可以捲動同用鍵盤操作，新訊息唔會搶焦點。

每個記錄包含識別碼、ISO 時間、種類、獨立英文同廣東話事實、關閉狀態，同可選嘅白名單恢復動作。顯示同讀出時先套用所選語言同趣味程度。個人詞彙映射、上載檔案名稱或內容，同解鎖憑證唔會加入呢個集合。匯入訊息係訪客提供嘅事實，未經服務驗證。

錯誤同警告保留至關閉。普通角落提示各自 8 秒後隱藏，集合記錄仍然保留。低刺激會隱藏普通角落提示，但保留記錄同需要處理嘅錯誤或警告。暫停語音同配合螢幕閱讀器獨立控制聲音。恢復動作會重試真正版本操作，或者開啟所屬偏好控制項。

中心有獨立文字搜尋同旁邊完整正則工具，格式最多 256 個字元，背景工具限時 200 ms。種類同關閉狀態篩選會同文字或正則結果一齊生效，每頁 20 個記錄。已註冊 Material 勾選框支援單項、Shift-click 範圍，同 Shift+Space 範圍選擇。「選擇呢頁」、「選擇所有符合記錄」、「反轉符合選擇」，同清除選擇都講明範圍。喺目前篩選以外嘅已選記錄會顯示數量，唔會加入動作、複製或匯出。

關閉同還原之前，會顯示真正已選記錄、將會修改數量，同因為已經係所需狀態而跳過嘅記錄。集合版本變更會令舊檢閱失效。修改會加入訪客歷史快照，還原歷史亦會加入新版本。未有不可逆刪除。複製保留原有雙語事實，剪貼簿權限失敗時會提示改用匯出。

篩選同已選記錄可以透過共用資料序列器，匯出適用嘅 JSON、JSONL、YAML、XML、CSV、TSV、HTML、SQL、Markdown 或純文字。下載前檢閱會講明 UTF-8，同格式限制：CSV/TSV 冇結構定義時會失去原有純量類型，類似公式嘅儲存格會加安全前綴，XML 用保留 JSON 類型嘅結構，SQL 只產生文字語句，唔會執行。除 CSV/TSV 記錄分隔用 CRLF，其餘用 LF，記錄文字保持原樣。其他通用格式同壓縮檔仍然未完成。

JSON 記錄陣列可以完整驗證同檢閱後取代集合。匯入最多 1 MiB 同 200 個記錄，會拒絕未知欄位、重複識別碼、無效種類、時間或動作，唔會部分套用。期間集合有修改，檢閱就會失效。訪客狀態版本 2 亦會連同偏好同其他訪客記錄，一齊轉移完整集合。

最多儲存 200 個記錄同 1 MiB。保留規則可能取代已關閉或普通記錄，但唔會靜靜取代未關閉錯誤同警告。如果全部記錄都需要處理，或者瀏覽器儲存失敗，新訊息會保留至今次瀏覽完畢，另外顯示儲存限制同恢復方式。歷史寫入失敗唔會取消要求嘅操作，會清楚講明冇可還原記錄。瀏覽器儲存係本機替代方式，唔係原生 Git 或加密憑證庫。

檢查包括結構拒絕、獨立錯誤堆疊、正確時間同安靜規則、保留策略、檢閱批次數量同過時憑證、JSON 往返、真正恢復路由、重新載入，同窄視窗雙語 Material 操作。200% 文字下原有導覽標籤重疊仍然係另外追蹤嘅顯示問題。
