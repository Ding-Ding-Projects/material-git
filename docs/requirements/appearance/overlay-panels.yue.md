# 浮層同面板

公開功能識別碼：`overlay-panels`。分類：**外觀及版面**。

## 要求嘅行為

每個彈出框、選單、下拉框、提示同錨定面板，都要有自己嘅背景、邊框、陰影層次同形狀，留喺視窗範圍內。內容放唔晒就捲動，唔隱藏溢出。浮層唔可以畫出卡片邊界、被開啟按鈕遮住，或者蓋住自己錨定嘅控制項。所有面板可以由邊同角調整大小；浮動面板亦可拖曳標題。兩者都要有鍵盤操作，大小同位置按介面儲存，並可重設。

## 目前支援同設定

已有 Material 浮層同可調整大小嘅應用程式面板；未證明所有面板支援拖曳、調整大小同儲存。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../scroll-surface.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

工作區導航寬度默認為 `250` px ，並接受 `190` – `380` ；底部面板高度預設為 `210` px ，並接受 `100` – `360` 。分割比例默認為 `50` ，並接受 `20` – `80` 。呢啲工作區界限唔會為每個錨定嘅浮層建立拖曳/調整大小嘅儲存及重新啟動行為。

## 失敗情況同剩餘工作

所有顯示比例下，逐個新浮層驗證視窗邊界，以及鍵盤拖曳、調整大小同重設。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
