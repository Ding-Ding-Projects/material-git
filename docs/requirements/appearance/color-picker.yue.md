# 連續選色同色彩空間轉換

公開功能識別碼：`color-picker`。分類：**外觀及版面**。

## 要求嘅行為

每個顏色控制都要用連續色譜、色輪或者二維色域，加數字輸入，唔可以只提供色板。轉換器要支援命名顏色、HEX／HEX8、RGB、HSL、HSV、HWB、CIELAB／LCH、OKLab／OKLCH 同 CMYK，保留透明度，講明目前色彩空間同色域，失去色域前警告，並顯示對比。彩虹動畫係其中一個選擇，以色板以外嘅特殊值表示；樣式表沿色輪播放，共用一個週期，速度按級別儲存，減少動態效果時固定一個色調。選擇器同周圍介面都要跟主題，有連接正規表達式建立器嘅搜尋，無法表示嘅值唔可以默默丟棄。

## 目前支援同設定

已有連續顏色輸入同轉換，並整合進階選擇器原始碼；唔代表所有色彩空間已驗證。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../converters.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

基本主題種子預設為 `#46b98b` ，並接受六位數十六進制。每個元素 HSL 通道接受色調 `0` – `360` 、飽和度/亮度 `0` – `100` 和 α `0` – `1` 。一般顏色轉換同每個進階顏色空間都要分開檢查；主題種子欄位唔可以代替無限選擇器要求。

## 失敗情況同剩餘工作

喺應用程式同網站逐個測試指定色彩空間、透明度、色域、對比、彩虹，同減少動態效果。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
