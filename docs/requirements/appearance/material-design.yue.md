# Material Design 3 一致性

公開功能識別碼：`material-design`。分類：**外觀及版面**。

## 要求嘅行為

所有有使用者介面嘅應用程式、GitHub Pages 同擴充功能頁面，都要完全符合 Material Design 3 Expressive 嘅設計變數、排版、形狀、陰影層次、動態效果同元件結構，唔保留舊設計或者自創設計元素。每個已渲染元件、控制項同版面都要使用已註冊嘅正版 Material Design 3 基礎元件；一般 HTML 只可用作文件處理或者已註冊元件內部。表示資料意義嘅顏色可保留，唔用呢個豁免改介面框架。要逐個介面人手記錄元件註冊同來源。

## 目前支援同設定

已有已註冊 Material 控制項同設計變數來源記錄；重製介面仍需重新完整稽核基礎元件。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../../design/material-provenance.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

渲染器匯入正版 `@material/web/all.js` 包，並註冊 `mg-surface` 、 `mg-text` 、 `mg-layout` 和 `mg-search` 組成。來源同實際渲染嘅解剖學係唔同嘅檢查：單單係註冊就唔可以證明所有新嘅控制項都符合參考。

## 失敗情況同剩餘工作

逐個渲染介面檢查真實註冊同來源，並加入故意替換錯誤元件會失敗嘅回歸檢查。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
