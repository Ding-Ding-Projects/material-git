# 功能性嘅用戶介面同埋真實嘅空狀態

公開功能識別碼：`functional-ui`。分類：**外觀及版面**。

## 要求嘅行為

任何看似可以使用嘅圖示、預覽、工具列控制、卡片、分頁、徽章或者操作提示，都要執行標示動作，提供無障礙等效操作，按需要儲存狀態，並有互動驗證。純粹示意嘅內容要標示為靜態預覽，唔可以裝成即時控制。發佈版要係真實應用程式，唔用假預設資料、樣本文檔或者只有模擬嘅流程；只顯示真實空狀態，並提供真正建立同開啟路徑。放棄未儲存工作時，要先寫入只新增嘅本機歷史，再完成關閉。

## 目前支援同設定

已整合原生工作領域操作同真實清單／詳情。操作對照表明確分開已登記嘅候選動作同實際互動驗證。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../coverage/github-actions-audit.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

工作領域編輯首先調用原生 `review` ，保留有界到期收據，然後用嗰張收據調用 `apply` 。更改欄位會令覆核無效。渲染器會阻止無效嘅表格，重複儲存，遺失收據同埋唔完整嘅破壞性確認；遠端權限同部分效果仍然係原生結果。

## 失敗情況同剩餘工作

透過最終介面逐個執行工作領域操作，驗證真實空狀態同錯誤、冇預填假實體，以及放棄草稿會先記錄。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
