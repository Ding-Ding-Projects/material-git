# 應用程式標誌自訂

公開功能識別碼：`logo-customization`。分類：**外觀及版面**。

## 要求嘅行為

每個有使用者介面嘅應用程式同 GitHub Pages，要提供幾款適合項目嘅標誌預設同本機自訂圖片上載，真實顯示空、載入、無效、已轉換、替換、重設同轉換問題狀態，並接上排程、外觀匯出、本機歷史、選單跳轉同逐元素編輯。隔離、有限制嘅本機解碼器要驗證真正位元組，拒絕損壞、動畫同解壓炸彈輸入，唔部分套用，圖片唔離開機器。編輯器提供裁剪、貼合、焦點、安全範圍同連續選色背景。轉換只產生已驗證可用格式，啟用前報告損失；失敗保留舊標誌，唔改已安裝產品身分。

## 目前支援同設定

已整合預設同本機自訂 PNG 呈現欄位；完整圖片編輯、解碼同轉換能力未驗證。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

`logoPreset` 默認 `git` ，有 `branches` 、 `merge` 和 `custom` 選擇。 `logoImage` 預設為空，並且必須係本地轉換後嘅 PNG 資料網址，而呢個網址唔長過 `49152` 字元。空/自訂/無效嘅轉換狀態同埋實際嘅標誌渲染仍然需要最終截圖；呢個限制唔會建立任意嘅圖片格式支援。

## 失敗情況同剩餘工作

驗證真正位元組上限、動畫／損壞／解壓炸彈输入、裁剪／圖層／重設，同各個保留產品身分嘅目的地。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
