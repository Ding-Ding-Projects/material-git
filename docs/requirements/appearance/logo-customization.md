# application logo customization

Public feature identifier: `logo-customization`. Category: **appearance**.

## Required behavior

Every user-facing application and GitHub Pages ships several project-appropriate logo presets plus a local custom-image upload, with truthful empty, loading, invalid, converted, replace, reset, and conversion issue states that join scheduled settings, appearance export, local history, palette teleport, and per-element editing. Custom images are decoded locally in an isolated bounded decoder that verifies the real bytes and rejects malformed, animated, or decompression-bomb input without partial application, and they never leave the machine. The editor offers crop, fit, focal point, safe area, and a background through the infinite colour picker, while conversion emits only verified consumable variants, reports any loss before activation, keeps the prior logo after a bug or failure, and never rewrites installed identity.

## Current support and configuration

Preset/custom local PNG presentation fields are integrated. Full image edit/decode/conversion coverage remains unverified.
