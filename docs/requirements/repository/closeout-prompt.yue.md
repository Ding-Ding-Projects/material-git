# 可複製收尾提示

公開功能識別碼：`closeout-prompt`。分類：**儲存庫記錄**。

## 要求嘅行為

每個處理儲存庫嘅回合，要喺根目錄 `CLOSEOUT_PROMPT.md` 寫可複製、有程式碼圍欄嘅收尾提示，取代舊副本，提交到負責分支、推送，回合完結前用 `git ls-remote` 核對遠端參照。公開版本經規範清理器同防漏掃描；提示冇變唔建立空提交。資源限制時仍必須推送。

## 目前支援同設定

可複製本機提示已提交；呢個工作分支唔執行分支推送或遠端參照驗證。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../../CLOSEOUT_PROMPT.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。


## 控制項、預設值同限制

`CLOSEOUT_PROMPT.md` 係可直接複製嘅本機延續記錄。已授權發佈擁有者必須核對已推送遠端參照。本機檔或提交唔證明分支已公開、網站已部署或者發佈已完成。

## 失敗情況同剩餘工作

主要發佈擁有者推送核准檢查點並核對遠端參照；缺少推送證據仍未完成。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
