# 持續 GitHub Discussion 記錄

公開功能識別碼：`discussion-records`。分類：**儲存庫記錄**。

## 要求嘅行為

主機支援時啟用 GitHub Discussions。每個進行中工作有一個持續進度 Discussion，經常留言真實里程碑；每個建置或發佈恰好一個變更 Announcement，留言記錄每次推送、Actions 結果同產物。最新代理建立公告置頂，只取消能證明由代理管理嘅舊置頂。

## 目前支援同設定

呢個唯讀工作分支未驗證 Discussion 啟用、持續工作、Announcement 或置頂狀態。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../../HANDOFF.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

已授權發佈擁有者記錄真實里程碑同產物，只替換證明由代理管理嘅置頂。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
