# 已清理私人細節嘅指引鏡像

公開功能識別碼：`sanitized-instruction-copy`。分類：**儲存庫記錄**。

## 要求嘅行為

每個項目喺 `README.md` 同 `AGENTS.md` 保留清楚標示、已清理私人細節嘅共用指引鏡像。指引改動時刷新；機器、帳戶、主機、路徑、地址同認證細節要泛化，唔只刪除。公開儲存庫鏡像省略全部私人詞彙。任何指引變更都先喺規範指引儲存庫做。

## 目前支援同設定

完整規範指引匯出目前未通過自己公開防漏檢查；清楚標示嘅項目專用摘要可安全公開。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`blocked`**。請睇[實作參考](../../requirements/shared-instructions.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

提交嘅指示文件明確係由正確嘅公共幫手匯出嘅項目特定摘要。完整嘅正規來源匯出仍然失敗咗佢自己嘅保護。唔好將摘要稱為位元組完整鏡像，或者喺呢個公開文件通道修復私人來源。

## 失敗情況同剩餘工作

先修正规範匯出，再用規範助手產生完整鏡像，泛化私人細節，公開前掃描。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
