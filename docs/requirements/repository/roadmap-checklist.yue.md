# 真實 ROADMAP 核取清單

公開功能識別碼：`roadmap-checklist`。分類：**儲存庫記錄**。

## 要求嘅行為

每個項目 `ROADMAP.md` 用真正 `- [ ]` 同 `- [x]` Markdown 核取方塊，按階段或里程碑分組，每次改項目工作都更新。剔選只喺已實作、已驗證同可見內容有截圖時先做。放棄項目要刪除線或者搬到明確唔做區，講原因，唔默默刪走。

## 目前支援同設定

全部 104 項要求仍有明確追蹤；未剔選代表實作或證據仍欠。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../../ROADMAP.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

真正嘅 `- [ ]` 同 `- [x]` 項目仍然係按階段/類別分組。未經控制嘅要求會保留佢嘅實施或證據差距。唔適用嘅範圍係解釋而唔係默默移除；研究檢查唔會閂 執行時 功能框。

## 失敗情況同剩餘工作

只有實作、驗證同截圖完成先剔選；放棄範圍要保留明確原因。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
