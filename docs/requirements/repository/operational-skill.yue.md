# 可重現項目操作技能

公開功能識別碼：`operational-skill`。分類：**儲存庫記錄**。

## 要求嘅行為

每次發佈級收尾，都產生或刷新一個儲存庫專用操作技能，記錄真正建置、封裝、完整介面操作、逐次截圖、證據、驗證、發佈同復原路徑，讓下一代理或實作子代理唔需重新摸索。私人流程留喺規範私人技能目錄；項目本機鏡像要清理私人細節。技能經 skill-creator 流程驗證。

## 目前支援同設定

已記錄公開可重現建置／稽核路徑；未有儲存庫專用操作技能經 skill-creator 驗證證據。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../../AGENTS.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

建立並驗證真正規範技能，包含真實介面、截圖、發佈同復原路徑，清理任何本機鏡像。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
