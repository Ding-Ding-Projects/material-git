# Tidbyt status frames

Public feature identifier: `tidbyt-displays`. Category: **status**.

## Required behavior

Registered Tidbyt displays receive an animated scrolling-marquee frame with a factual progress bar on every Git worktree creation, push, implementation subagent spawn and completion, multi-agent orchestration mode launch, Docker deployment, large private heading, and panic activation and relief, with an animated `IDLE` frame at 100% once work goes idle. Frames use the private vocabulary, are sent with an `installationID`, batch simultaneous events, and keep the raw WebP within the host route's 32 KiB cap. An unreachable Hub is stated plainly, never claimed as a sent frame.
