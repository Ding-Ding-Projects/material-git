# 非阻塞通知同通知歷史

公開功能識別碼：`notifications`。分類：**記錄及匯出**。

## 要求嘅行為

資訊、成功、進度同唔需要決定嘅問題訊息，用錨定底角嘅非阻塞短暫通知。除咗問題、失敗同警告以外自動關閉；堆疊唔重疊，可帶動作。模態對話框只留畀真正決定。通知中心／歷史保留已關閉通知，可覆查、搜尋同批次管理。每個通知都要本機化、可聚焦、可公告、對比足夠，同有足夠尺寸嘅關閉目標。

## 目前支援同設定

已有會儲存、有限制嘅通知狀態／動作，同經覆核記錄匯出；最終介面所有事件整合仍未驗證。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../workspace.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

通知種類有 `info`、`success`、`warning` 同 `error`，另有時間戳、標題、已讀／關閉狀態同可選動作識別碼。標題上限 `240` 字元，集合最多 `500` 項。會儲存嘅原生記錄同外殼短暫通知計時器分開處理。

## 失敗情況同剩餘工作

操作驗證警告保留、短暫通知堆疊／動作、焦點／公告、關閉／重新啟動／搜尋，同有明確範圍嘅批次操作。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
