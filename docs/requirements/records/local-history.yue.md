# 隔離本機 Git 歷史

公開功能識別碼：`local-history`。分類：**記錄及匯出**。

## 要求嘅行為

擁有文件、項目或者使用者管理記錄嘅應用程式，要喺自己資料目錄旁邊保留隔離 Git 歷史，唔喺使用者資料夾建立 `.git`。文件、帳戶、認證、連接服務、規則同設定都要涵蓋，讓變更可復原。復原產生新修訂，歷史只新增；密文快照保持密文，認證加密綁定復原後仍有效，修訂如實標示改動。面板提供瀏覽、差異、復原、標記、修剪同匯出，有進階日期選擇器、由真實動作產生並有數目嘅篩選，同自己嘅正規表達式搜尋。秘密同顯示名稱遵守密碼保護變更歷史規則，每次變更一個提交，冇明文秘密。

## 目前支援同設定

已有隔離 Git 工作區／外部記錄歷史，移除敏感資料後儲存，並有非同步復原派發；完整逐類型復原介面同整合入口仍未完成。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../workspace.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

記錄放喺隔離、由應用程式擁有嘅 Git 儲存空間。復原派發係非同步，各類資料驗證由可信原生復原處理器負責。移除敏感資料嘅程序排除秘密、草稿、內容同提供者欄位，可能保留密文。放棄記錄只保留分頁／版面中繼資料，唔係可復原草稿文字。

## 失敗情況同剩餘工作

證明每次真實變更只有一個修訂；設定、帳戶、加密認證因子、排程同放棄記錄復原都只新增歷史，唔使用明文權杖。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
