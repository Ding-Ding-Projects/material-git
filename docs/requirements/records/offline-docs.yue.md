# 程式內離線文件

公開功能識別碼：`offline-docs`。分類：**記錄及匯出**。

## 要求嘅行為

每個 GUI 應用程式，要喺建置時包含每篇功能文章，提供完整離線瀏覽器，使用同一個共用 Markdown 渲染器；呢個係 GitHub Pages 文章以外嘅獨立功能。文章連結喺程式內解析，瀏覽器有標題同全文正規表達式搜尋。儲存庫有文章但建置包缺少時，完整性檢查必須令建置失敗。

## 目前支援同設定

即時載入全部文章嘅建置同共用渲染器，已有故意漏文章先失敗、補回後通過嘅檢查，亦有隔離 Electron 文章導覽證據。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`not-applicable`；儲存庫：`not-applicable`**。請睇[實作參考](../../workspace.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

建置時 `import.meta.glob` 即時包含全部 `docs/**/*.md` 文章。共用安全 Markdown 渲染器喺程式內解析已知相對文章連結。瀏覽器每頁 `10` 個索引項目，搜尋標題同全文。建置防漏檢查會解碼 JavaScript，驗證每個文章路徑對應完整原文；缺少、修改或者對調文章都拒絕。

## 失敗情況同剩餘工作

新增文章後重新操作最終建置；逐篇驗證文章／全文搜尋、相對連結同完全離線使用。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
