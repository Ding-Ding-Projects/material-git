# 內置 TOTP 驗證器

公開功能識別碼：`authenticator`。分類：**確認、鎖定及驗證**。

## 要求嘅行為

每個有使用者介面嘅應用程式，都要有普通分頁、可搜尋同選單可到達嘅驗證器，接受任意 TOTP 秘密。可用 `otpauth://` URI、圖片或剪貼簿 QR、可用相機，或者手動 base32 註冊。驗證碼按 RFC 6238 建基於 RFC 4226，支援 SHA-1、SHA-256、SHA-512、6 至 8 位數同任意週期，並用公開測試向量驗證。大字顯示，可複製，有清晰倒數同下一個碼預覽；時鐘偏差用普通文字說明。所有資料留喺本機作業系統認證保管庫；普通匯出省略秘密並講明，秘密匯出必須經超級確認。

## 目前支援同設定

原生 RFC TOTP 驗證同加密記錄已有測試；QR 圖片、相機、最終介面同各平台仍需獨立證據。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../security.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

本機 TOTP 預設 `SHA1`、`6` 位數同 `30` 秒週期。接受 `SHA1`／`SHA256`／`SHA512`、`6`／`7`／`8` 位數，同 `1`–`86400` 秒週期，最多儲存 `100` 項。驗證碼用系統時鐘；`clockVerified: false` 表示未作可信外部時鐘核對。

## 失敗情況同剩餘工作

驗證 RFC 向量、演演算法／位數／週期、倒數／時鐘偏差、所有註冊路徑同敏感匯出確認。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
