# 免費預設同誠實收費

公開功能識別碼：`honest-monetization`。分類：**確認、鎖定及驗證**。

## 要求嘅行為

新應用程式預設免費，只有擁有者刻意決定先可收費。無障礙、三種語言、兩條搞笑程度、School mode、解鎖階梯，同個人資料匯入／匯出都唔可設付費門檻，亦唔會到期。購買介面要列明確切價格、供應數量同所有授權限制；付款認證同簽署密鑰按一般秘密規則處理。唔發出未被要求嘅付款、捐款、評論、升級或者支援提示。建基於別人工作嘅應用程式，其捐款應指向原作者。

## 目前支援同設定

項目免費，冇需要使用者付款嘅流程；冇營利係刻意嘅預設。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../../README.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

檢查最終程式同網站冇未被要求嘅付款／評論提示；無障礙同個人資料匯出仍免費。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
