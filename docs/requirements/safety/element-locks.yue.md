# 逐元素鎖定

公開功能識別碼：`element-locks`。分類：**確認、鎖定及驗證**。

## 要求嘅行為

每個已渲染元素、分頁、分頁群組同外觀值，都可從 **鎖定呢個元素…** 開啟非模態錨定精靈，選擇六種組合之一：PIN、密碼、PIN＋密碼、密碼＋TOTP、PIN＋TOTP，或者密碼＋PIN＋TOTP。每個鎖喺作業系統認證保管庫有獨立認證，冇主認證或者隱含繼承。鎖定元素真正停用但可開啟自己嘅錨定解鎖提示；快捷鍵、選單跳轉同自動化入口都唔可以繞過。每個鎖講明只供趣味用途、唔係安全保護；復原方法係刪除本機應用程式資料資料夾。

## 目前支援同設定

已整合六種逐目標認證政策、原生目標登記同鎖定檢查；只有介面攔截唔係安全界線。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../security.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

政策係 `pin`、`password`、`pin-password`、`password-totp`、`pin-totp` 同 `password-pin-totp`。解鎖可限呢個介面／動作、應用程式工作階段，或者 `1`–`1440` 分鐘。原生目標用穩定識別碼登記，變更時再檢查鎖；只有 DOM 攔截唔足夠。

## 失敗情況同剩餘工作

驗證右鍵、鍵盤、選單同自動化路由、獨立認證、到期／工作階段／單操作政策同保管庫失敗。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
