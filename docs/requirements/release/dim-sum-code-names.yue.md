# 版本旁嘅點心代號

公開功能識別碼：`dim-sum-code-names`。分類：**發佈流程**。

## 要求嘅行為

每個建置或發佈版本旁要有點心代號，精確使用公開目錄嘅 `name.en` 同 `name.zhHant`，只選相片已公開菜式，每項目只用一次並有可稽核記錄。代號同公開相片連結出現喺發佈說明、變更瀏覽器、網站發佈區同關於，所有搞笑程度下名稱都如實。目錄不可用唔阻塞、延遲或者改名發佈。

## 目前支援同設定

下一個建置／發佈代號對照同所有顯示位置，仍需發佈清單證據。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`partial`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

只用相片已發佈、未曾使用嘅精確公開英文／廣東話名；缺少目錄唔可以阻塞發佈。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
