# 應用程式顯示名稱

公開功能識別碼：`display-name`。分類：**語言及個人化**。

## 要求嘅行為

使用者可以更改應用程式喺標題列、關於、通知同其他自我介紹位置顯示嘅名稱；設定要儲存，並可一個動作重設為原有名稱。改名只影響顯示名稱：資料目錄、安裝程式同套件識別碼、更新來源、寫入其他儲存庫嘅標記，仍然由固定常數決定；診斷同當機報告仍用原有产品名稱。每次改名、變更同重設，都要喺應用程式本機歷史記錄一個只新增、唔改寫舊記錄嘅提交。

## 目前支援同設定

顯示名稱作為已儲存呈現值；固定產品身分保持獨立。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`not-applicable`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

`displayName` 預設為 `Material Git` ，必須包含非空格文字，並且受一般 `256` 字元字串限制所界定。佢係呈現狀態：安裝程式身分、資料路徑同更新身分保持恆定。每個標題/關於/通知嘅使用仍然需要佢自己嘅最終互動檢查。

## 失敗情況同剩餘工作

一齊驗證標題、關於同通知；檢查重設同每次變更都各有移除敏感資料、只新增嘅歷史修訂。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
