# 語音旁白同聲音選擇

公開功能識別碼：`narration`。分類：**語言及個人化**。

## 要求嘅行為

每個有使用者介面嘅應用程式都要提供事件語音旁白，預設關閉，只由使用者自行開啟。英文、廣東話同雙語旁白要逐句依序播放，廣東話使用香港廣東話聲音。每種語言有獨立聲音選擇器，只列出機器實際提供嘅聲音，預設 **自動選擇**，儲存穩定聲音識別碼，處理延遲出現嘅聲音清單，並喺下方講明實際使用嘅聲音。速度同音高可以調整。短時間重複事件要合併，每類有播放頻率限制，一次只讀一句；唔可以省略問題事實，偵測到螢幕閱讀器時要讓路。

## 目前支援同設定

已提供機器聲音偵測同依序旁白；實際聲音選擇取決於作業系統。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

旁白開始： `narrator: false` 。 `narrationLanguage` 默認為 `en` ；空 `englishVoice` / `cantoneseVoice` 表示自動選擇。 `speechRate` 默認 `1` ，並且允許 `0.5` – `2` ； `speechPitch` 默認 `1` ，並且允許 `0` – `2` 。 `screenReaderActive` 和 `quietNarration` 默認為 `false` ；部機一定要提供一個適合嘅聲音。

## 失敗情況同剩餘工作

驗證聲音清單延遲／空清單、冇廣東話聲音、螢幕閱讀器互動，同速度／音高上限。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
