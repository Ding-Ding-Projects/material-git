# 點心驚喜

公開功能識別碼：`dim-sum`。分類：**語言及個人化**。

## 要求嘅行為

每個有使用者介面嘅應用程式，每次啟動重新抽一次，有 10% 機會顯示一款隨機點心嘅英文名、廣東話名同相片，每次啟動最多一次。提示唔阻塞操作、會自動關閉，唔延誤啟動或者搶走焦點；首次使用、問題或失敗、更新、工作進行中都唔顯示。要尊重減少動態效果同安靜設定，替代文字講明點心名稱。唔設退出選項；舊關閉開關要移除並遷移已儲存偏好。School mode 會抑制提示；相片只可來自 `dim-sum-photo-source` 指定嘅公開目錄，兩項要求要一齊閱讀。

## 目前支援同設定

目前渲染器同原生原始碼未提供啟動驚喜或相片處理。呢項要求仍然未實作，文件唔算功能證據。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`open`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

驗證 10% 啟動抽籤同每次最多一次；首次使用、忙碌、錯誤、更新同 School mode 都要抑制。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
