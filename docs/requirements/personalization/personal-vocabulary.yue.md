# 本地個人詞彙 JSON 上載

公開功能識別碼：`personal-vocabulary`。分類：**語言及個人化**。

## 要求嘅行為

每個有使用者介面嘅應用程式同 GitHub Pages，都要喺自己嘅設定顯示本機個人詞彙 JSON 上載控制項，即使未有檔案亦要見到。冇檔案、已載入、無效、替換、清除同重設狀態都要本地化，並可經設定搜尋同指令選單搵到。資料結構要有文件、版本同大小上限，顯示或快取之前完整驗證；拒絕嘅檔案唔可以部分套用，清除會刪除快取。未有有效私人檔案之前，顯示產品原有文字。處理只喺本機進行，私人詞彙、對照、資料內容同檔案中繼資料，唔可以進入原始碼、日誌、匯出、歷史、遙測、提示或者公開記錄。

## 目前支援同設定

已實作有大小上限嘅本機資料結構驗證同私人快取；同普通匯出分開處理。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

本地匯入接受資料結構 `schemaVersion: 1` 同 `entries` 對象，最多接受 `65536` UTF-8 位元組同 `256` 對應。鍵係 `1` – `128` 字符同替換 `1` – `256` ；喺應用程式之前，系統會拒絕重複/唔安全嘅 JSON 鍵同控制字元。絕對唔好用私人檔案做已發佈嘅測試工具。

## 失敗情況同剩餘工作

喺最終建置逐一操作空狀態、上載、無效、替換、清除、重複鍵、重新啟動同離線情況；驗證過程唔記錄私人值。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
