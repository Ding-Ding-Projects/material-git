# 公共點心相片來源

公開功能識別碼：`dim-sum-photo-source`。分類：**語言及個人化**。

## 要求嘅行為

代理唔可以喺使用相片嘅產品儲存庫生成、下載、擷取或者隨程式附帶點心相片。唯一公開來源係 `Ding-Ding-Projects/dim-sum-photos`，名稱以 `catalog/index.json` 為準，相片只用已發佈嘅 `catalog-v1*` 資產，經公開網址或者應用程式資料快取存取。公開相片缺失時省略並報告，唔可以喺本機補造。儲存庫內舊相片只供遷移，應移走。`Ding-Ding-Projects/dim-sum-catalog-archive` 只供復原同稽核儲存，唔係產品取圖來源。

## 目前支援同設定

公開相片目錄同發佈資產係指定來源政策；本次稽核未見執行時擷取、快取同相片不可用处理。只有政策唔代表功能已實作。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`open`；網站：`unknown`；儲存庫：`open`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

驗證目錄修訂、快取來源同真正相片不可用情況；唔提交產品內相片副本。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
