# 預定同外部設定來源

公開功能識別碼：`scheduled-settings`。分類：**語言及個人化**。

## 要求嘅行為

每個有使用者介面嘅應用程式同 GitHub Pages，都要提供會儲存嘅排程介面，涵蓋語言、主題、密度、種子顏色、字體、動態效果、顯示名稱同其他外觀或自訂值。日期同時間用原生無障礙選擇器，並講明時區同夏令時間處理。規則用有版本同大小上限嘅結構、穩定識別碼同確定優先次序；值可來自本機、經驗證有版本嘅 HTTPS API，或者 Home Assistant 布林實體。外部來源喺有上限嘅間隔刷新，用請求世代檢查避免舊回應覆蓋新值。失敗時安全退回最後有效嘅基本設定並發出本地化通知；權杖留喺作業系統認證保管庫，API 值唔可以寫成永久基本設定。

## 目前支援同設定

已整合偏好服務，將本機、HTTPS 同 Home Assistant 規則同基本設定分開計算；認證權杖獨立儲存。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

時間表由冇規則/連線同埋機器嘅 IANA 時區開始。資料結構版本 `1` 允許 `64` 規則、 `16` 批准嘅連接同埋 `262144` 位元組。刷新係 `30` – `3600` 秒；回應上限係 `65536` 位元組同超時 `8000` 毫秒。窗口使用 `[start,end)` ；等於時間即係全日。過夜規則屬於佢哋嘅開始日期/平日，重複嘅 DST 時間會匹配兩次，而唔存在嘅牆時間永遠唔會發生。

## 失敗情況同剩餘工作

重新操作驗證跨午夜、夏令時間、離線、過期請求世代、所有外觀值、需要認證嘅來源同記錄復原。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
