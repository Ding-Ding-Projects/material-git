# 通用 School mode

公開功能識別碼：`school-mode`。分類：**語言及個人化**。

## 要求嘅行為

School mode 只有一個共用、可以由使用者改名嘅開關，儲存喺共用本機應用程式資料記錄；任何地方開啟，所有地方都要即時跟隨，唔使重新啟動。改名後只顯示所選名稱。開啟時強制英文，將廣東話、雙語、搞笑程度、個人詞彙同所有點心功能當作未安裝，完全省略控制項、路由、結果同參考資料；解鎖階梯由算術題開始。關閉需要共用並喺本機驗證嘅 PIN、密碼或者通行鍵。控制項要講清楚，呢個係使用體驗鎖，刪除共用記錄會重設，唔係安全界線。

## 目前支援同設定

原生安全同偏好服務已有共用 School mode，以及改名同隱藏功能控制。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../security.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

要驗證每個產品介面跨實例即時同步、完全隱藏相關路由同控制項，以及經認證先關閉模式。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本地化。
