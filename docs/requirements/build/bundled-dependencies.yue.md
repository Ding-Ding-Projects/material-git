# 安裝包內包含所需依賴

公開功能識別碼：`bundled-dependencies`。分類：**建置及安裝**。

## 要求嘅行為

所有有使用者介面嘅應用程式，要喺自己安裝包包含所需全部依賴，拔掉網絡仍可用。「先安裝 X 再試」係缺陷；優先可攜分發。授權禁止再分發時，需已驗證自動取得，唔只畀連結。優先使用隨包版本，講明用緊邊份；找唔到時列全部搜尋路徑。要由真正已安裝產物證明，唔只睇設定。編輯器等可選整合仍可係連結，文字唔當成欠缺所需依賴。

## 目前支援同設定

Windows 包含 GitHub CLI 同 MinGit；通用轉換／執行時依賴同拔網後已安裝行為仍未完整。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`not-applicable`；儲存庫：`not-applicable`**。請睇[實作參考](../../build.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

檢查已安裝產物路徑、版本、授權同離線操作；可選外部編輯器另行識別。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
