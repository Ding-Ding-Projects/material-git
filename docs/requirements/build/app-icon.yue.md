# 原創標誌同真正套件圖示

公開功能識別碼：`app-icon`。分類：**建置及安裝**。

## 要求嘅行為

發佈前，所有有介面應用程式要有原創、適合項目標誌同真正套件圖示，由已提交主來源產生有效平台格式，Windows 包含多尺寸 `.ico`。接上介面、可執行檔、安裝包同更新中繼資料。框架預設、缺少標誌、可變或不可達圖示網址，或者只改名嘅點陣圖，都阻止發佈級收尾。要喺建置產物檢查小尺寸同一般尺寸。

## 目前支援同設定

已有項目主來源同平台圖示產生；真正 Windows 介面、安裝包同更新圖示檢查仍待完成。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../../design/material-provenance.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

核對原創已提交來源、多尺寸 ICO，同封裝後小／一般尺寸。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
