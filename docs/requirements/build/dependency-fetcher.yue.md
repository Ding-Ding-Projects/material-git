# 固定版本依賴下載

公開功能識別碼：`dependency-fetcher`。分類：**建置及安裝**。

## 要求嘅行為

每個儲存庫要有 `download-dependencies.bat`；支援其他平台時亦有 `download-dependencies.sh`。從官方來源將建置、運行同測試全部依賴下載到使用者範圍，固定精確版本、核對記錄摘要，並提交版本同摘要清單。可重複執行、支援安靜模式、按階段報告，第一次真正失敗即非零結束。唔提交下載依賴，唔安裝秘密或簽署憑證；`build.bat` 呼叫呢個腳本，唔重複實作。

## 目前支援同設定

已有固定版本腳本依賴取得，同已核對 gh／MinGit 套件；完整全新快取未命中流程仍待驗證。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../build.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

固定 GitHub CLI 版本 `2.102.0`；Windows MinGit `2.56.0.2`，執行回報 `2.56.0.windows.2`。下載啟用核對已記錄摘要。Linux 開發目前用 Git `2.52.0`；可選 LFS 同外部工具係獨立能力，唔會自動將開發 PATH 工具放入安裝包。

## 失敗情況同剩餘工作

列出全部建置／運行／測試依賴，證明官方網址、摘要、使用者範圍、可重複性同精確失敗結束碼。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
