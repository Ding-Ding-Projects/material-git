# 根目錄 Windows 建置入口

公開功能識別碼：`build-entrypoints`。分類：**建置及安裝**。

## 要求嘅行為

每個儲存庫要有真正有效嘅根目錄 `build.bat` 同 `build-installer.bat`，將全新 Microsoft Windows checkout 建置成可運行程式同等同發佈嘅安裝包。自行喺使用者範圍安裝全部依賴，互動時預先提權，支援 `/s`、`--silent` 同 `SILENT=1`。如實報告階段，可重複安全執行，傳遞真正子程序結束碼。所有建置同安裝包製作，包括手動發佈，都呼叫呢兩個入口。安裝腳本核對並顯示產物路徑同 SHA-256，唔發佈、加標籤或者推送。冇可安裝目標嘅儲存庫要記錄精確不適用範圍，唔假報成功。

## 目前支援同設定

已有根目錄批次入口同固定版本依賴下載；本機未驗證全新 Windows 機器執行。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../build.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。


## 控制項、預設值同限制

使用者入口係 `build.bat`、`build-installer.bat` 同 `download-dependencies.bat`；README 顯示 `build.bat --run`。安靜模式同全新使用者範圍初始化，需真正 Windows 執行；Linux 原始碼建置成功係另一項檢查。

## 失敗情況同剩餘工作

證明安靜／可重複使用者範圍初始化、真正子程序失敗、安裝包摘要，同建置腳本唔發佈。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
