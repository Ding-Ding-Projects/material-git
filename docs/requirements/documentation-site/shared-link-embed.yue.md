# 真實產品連結預覽

公開功能識別碼：`shared-link-embed`。分類：**文件網站**。

## 要求嘅行為

每個儲存庫同發佈頁面，分享連結要顯示真正產品大圖，唔用自動中繼資料卡、素材圖或者設計圖。根目錄提交 `social-preview.png`；伺服器副本由同一腳本產生，證明位元組一致。每頁伺服器 HTML 包含 `og:` 標題、描述、網址、類型、網站名，同絕對 `https://` 圖片、寬高、替代文字；`twitter:card` 用 `summary_large_image`，另有 `theme-color`。圖片可匿名取得，唔被爬蟲政策禁止，內容改時網址亦改。手動儲存庫預覽上載要交畀使用者，提供精確根路徑並追蹤確認。

## 目前支援同設定

未驗證目前根目錄社交預覽圖、匿名取得副本位元組，同爬蟲中繼資料一致性。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`unknown`；儲存庫：`partial`**。請睇[實作參考](../../site.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。


## 失敗情況同剩餘工作

由真正產品截圖產生預覽，匿名驗證伺服器中繼資料同圖片位元組，記錄手動儲存庫預覽上載狀態。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
