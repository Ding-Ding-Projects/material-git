# 獨立文件同下載網站

公開功能識別碼：`landing-site`。分類：**文件網站**。

## 要求嘅行為

公開儲存庫應用程式要有 Material Design 3 GitHub Pages，私有儲存庫唔強制建立。已有網站係介紹、文件、下載、狀態、設定同連結介面，要清楚講明，唔係主要執行環境、可玩遊戲或者產品嵌入仿製。所有適用規範功能，要有操作網站自身內容同訪客本機儲存嘅等效功能，用人手逐項清單；漏項令文件建置失敗。網站同樣可自訂同有分頁，介紹項目全部功能，資產全隨網站提供，唔用 CDN、託管字體或者分析，講明文件版本，唔將未發佈功能當已交付。

## 目前支援同設定

文件網站重製同生產性桌面分開處理，目前網站只供擁有者。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../site.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

實作所有適用訪客功能、本機資產／設定／文件同如實版本，另行驗證部署。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
