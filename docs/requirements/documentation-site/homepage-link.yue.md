# 儲存庫 About 同首頁連結

公開功能識別碼：`homepage-link`。分類：**文件網站**。

## 要求嘅行為

公開儲存庫應用程式嘅 GitHub About 網站欄位 `homepage`，要設為已驗證部署嘅精確 GitHub Pages 首頁網址。私有儲存庫唔強制呢個欄位，可選私有網站仍容許。用 `gh repo edit --homepage <url>` 設定，README 上方亦連結。經 GitHub Pages 發佈時啟用發布；網址同基本路徑可設定，並喺建置驗證，避免 fork 以項目路徑發佈後 404。

## 目前支援同設定

README 已連結精確網站網址；About homepage PATCH 因目前認證缺少中繼資料權限而回覆 HTTP403。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`not-applicable`；網站：`blocked`；儲存庫：`blocked`**。請睇[實作參考](../../../README.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

所需精確首頁係 `https://material-git.earlyray.chatgpt.site`。README 已有連結；目前認證執行儲存庫 About PATCH 回覆 `HTTP 403`。改原始碼唔會改遠端權限，亦唔會改網站只供擁有者嘅可見範圍。

## 失敗情況同剩餘工作

發佈擁有者需處理已授權權限並核對 About 網址；網站仍只供擁有者，唔自行改可見範圍。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
