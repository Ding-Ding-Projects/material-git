# `Ctrl+Shift+F` 指令選單

公開功能識別碼：`command-palette`。分類：**導覽及搜尋**。

## 要求嘅行為

所有有使用者介面嘅應用程式同 GitHub Pages，用 `Ctrl+Shift+F` 開啟指令選單，唔設競爭嘅 `Ctrl+K` 預設。選單涵蓋所有操作、功能頁、文章、目的地、設定同外觀控制。結果列係接上原來程式碼嘅真實豐富控制；選擇後跳到真正元素所屬介面、分頁或群組、捲動位置同焦點，短暫突出目標。大小可儲存，選擇預設有限卡片或者全視窗，並有自己嘅搜尋同正規表達式建立器。

## 目前支援同設定

選單索引目的地、設定、文章同目前控制項；跨 shadow root 排除未啟用但仍掛載嘅分頁，唔顯示 CLI 指令登記清單。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../workspace.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

用 `Ctrl+Shift+F` 開啟。`paletteSize` 預設 `card`，亦可選 `window`。每頁 `20` 個結果，涵蓋目的地、設定、文章同目前頁面控制項。跨 shadow root 排除隱藏未啟用分頁同選單自身控制。操作係目前工作任務，唔係原始 CLI 清單。

## 失敗情況同剩餘工作

驗證 Ctrl+Shift+F、大小儲存、跳到正確擁有路由，以及所有可操作設定同目前介面控制項。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
