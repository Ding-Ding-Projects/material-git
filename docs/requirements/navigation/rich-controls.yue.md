# 顯示值時提供真實控制項

公開功能識別碼：`rich-controls`。分類：**導覽及搜尋**。

## 要求嘅行為

清單列、表格儲存格、選單項目、搜尋結果、詳情面板、卡片同預覽顯示值時，優先用真實控制項，唔只印出文字。驗證、儲存、本機化、搞笑程度、歷史同無障礙名稱，要同原本介面共用。只有講明原因先可只讀顯示，完整控制必須一個明顯動作就到。長清單要虛擬化並易於遍歷；每個嵌入控制都有自己嘅名稱、角色、值、狀態、焦點同足夠操作尺寸。

## 目前支援同設定

專用工作領域表單同資料結構控制已有具類型選擇器，但唔係每個顯示值都係即時豐富控制。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../api-explorer.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

稽核結果、表格、選單同詳情值；檢查原生驗證重用、焦點同長清單效能。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
