# 每個搜尋介面嘅正規表達式工具

公開功能識別碼：`regex-search`。分類：**導覽及搜尋**。

## 要求嘅行為

每個項目要喺自然主要介面提供進階正規表達式工作台，用真正引擎建立、解釋、測試、分析效能同除錯。每個搜尋欄、設定／屬性、頁面、面板、清單、表格、樹、圖庫、歷史、通知中心、編輯器區、下拉框同右鍵選單，都有自己嘅本機搜尋同旁邊錨定建立器。查詢、模式、旗標、驗證、搜尋方式、歷史同片段互相獨立，預設純文字。運算只喺本機，有大小同時間限制，防止災難性回溯；人手逐介面清單要令漏咗嘅搜尋欄被檢查發現。

## 目前支援同設定

已有受限制嘅本機正規表達式工作台同逐搜尋元件；重製介面未完成所有搜尋覆蓋。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../regex.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

逐個清單、樹、編輯器、下拉框同選單檢查獨立查詢／建立器、效能分析、超時同災難性模式防護。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
