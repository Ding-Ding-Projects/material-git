# 瀏覽器式分頁導覽

公開功能識別碼：`tabs`。分類：**導覽及搜尋**。

## 要求嘅行為

所有有使用者介面嘅應用程式同 GitHub Pages，都要以瀏覽器式分頁呈現內容。分頁列可停靠四邊，預設左邊，有符合方向嘅無障礙行為、更多分頁入口、排序、固定、群組同群組裝飾；順序、固定、群組同收合狀態重新啟動後仍保留。設定、屬性同外觀亦有完整分頁功能同自己嘅搜尋。每個應用程式提供四種獨立分頁探索搜尋，用 **移動到群組…** 選擇器，唔用內嵌群組清單；**關閉包含文字嘅分頁** 同 **關閉唔包含文字嘅分頁** 都要有預覽、排除固定分頁同正規表達式建立器。

## 目前支援同設定

可重用分頁管理已有儲存測試、資料測試同真實隔離 Electron 操作／重啟證據；最終介面整合仍需新截圖。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../workspace.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

有版本嘅工作區最多 `100` 個分頁同 `40` 個群組。可重用元件預設停靠 `left`；目前外殼嘅儲存庫工作區用 `top` 分頁列，起初隱藏。順序、固定、群組、收合中繼資料同分割版面會儲存，敏感草稿值唔會。方向鍵導覽、`Alt+Shift+Arrow` 排序同 `Ctrl+Shift+P` 固定都有鍵盤路徑。

## 失敗情況同剩餘工作

用真實工作領域草稿驗證四種獨立搜尋、四邊停靠、群組／固定／排序／溢出，以及受保護嘅批次關閉。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
