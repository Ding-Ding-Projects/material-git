# 會解釋自己嘅設定

公開功能識別碼：`settings-explanations`。分類：**導覽及搜尋**。

## 要求嘅行為

每個設定元素都要透過按需要展開提供完整解釋，講明作用，唔只重複標籤。旁邊如實講明值來自已寫入檔案或者程式內建預設，並列出真正預設值。每個設定元素有手寫覆蓋清單；任何元素冇解釋，驗證就要失敗。

## 目前支援同設定

已整合設定中繼資料同已儲存鍵來源；新控制項仍需完整解釋清單檢查。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../personalization.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

`settingsFields` 列出所有 `AppSettings` 鍵、實際類型、枚舉選項同數字範圍。初始化另行提供 `persistedSettingsKeys`。介面要分清楚已儲存基本值、實際生效排程值同程式內建預設，唔可以將預設當成磁碟讀取值。

## 失敗情況同剩餘工作

逐個設定鍵同控制項對照手寫必需欄位，解釋實際生效值、來源、基本值同真正預設。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
