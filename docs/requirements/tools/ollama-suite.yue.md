# 完整本機 Ollama 管理

公開功能識別碼：`ollama-suite`。分類：**本機工具**。

## 要求嘅行為

每個有使用者介面嘅應用程式同 GitHub Pages，要獨立提供基於 Ollama 官方本機 HTTP API 嘅完整管理器。產品內有真實選擇器、建議預設、解釋同離線疑難排解，唔可以只叫人睇網上文件。每次經驗證刷新，Model Store 列出完整官方目錄同所有標籤；硬件適配按證據評為 **運行良好**、**有限制**、**不大可能** 或 **未知**。購物車只代表批次下載，唔係付款。聊天係完整本機工作階段，附件按能力開啟。啟動本機工具設定檔係允許清單編排，有預檢、預覽、快照、一按復原同自動回滾，唔執行任意 shell。

## 目前支援同設定

已整合原生模型目錄遍歷、硬件證據、經覆核並儲存嘅批次下載、會儲存嘅串流聊天，同允許清單工具生命週期。完整即時目錄／標籤／GPU／附件／平台證據仍未齊。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../ollama.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

目錄每頁預設 `40` 項（`1`–`100`），遍歷最多 `10000` 個官方頁面。經覆核下載批次接受 `1`–`100` 個精確標籤，並行 `1`–`3`，預設 `1`。串流上限 `8` MiB；最多儲存 `500` 個工作階段，每個最多 `128` 訊息同 `1` MiB。就算偵測到 VRAM，GPU 後端相容性仍未證明，適配評估可以如實保持未知。

## 失敗情況同剩餘工作

稽核完整 API 操作對照、附件能力、取消、秘密儲存、離線疑難排解同回滾。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
