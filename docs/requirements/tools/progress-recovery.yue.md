# 原位置進度同失敗復原

公開功能識別碼：`progress-recovery`。分類：**本機工具**。

## 要求嘅行為

啟動長操作嘅對話框，要喺對話框內顯示真實進度，停用提交控制，處理器亦拒絕重入。慢而可選階段要明確選擇，講明拒絕會留下乜未做。使用者難以診斷嘅問題或失敗，要喺原控制旁提供復原。交接本機程式代理時講明真實情況，禁止會失去工作嘅補救，例如強制推送。認證拒絕或欠權限，要就地提供重新認證。

## 目前支援同設定

已有原生經覆核操作、受限制輸出同取消；每個新動作仍需原位置進度同復原。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../coverage/git-actions-audit.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

工作領域 `saving` 狀態阻止重複提交，透過外殼顯示真正待處理工作。套用失敗會清除覆核收據，重試前需重新覆核。衝突、權限拒絕同部分遠端效果，要保留各自復原狀態；普通成功通知唔可以代替核對。

## 失敗情況同剩餘工作

阻止處理器重入、保留部分結果，喺原控制旁提供重新認證或安全復原。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
