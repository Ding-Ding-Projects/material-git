# 真正本機檔案轉換

公開功能識別碼：`file-converter`。分類：**本機工具**。

## 要求嘅行為

每個有使用者介面嘅應用程式同 GitHub Pages，要提供真正本機轉換器，用有限位元組檢查偵測格式。分類、可搜尋嘅轉接器目錄，至少包含文件／PDF、圖片、音訊、影片、封存、結構資料／試算表、程式碼／文字，同二進位編碼。未能使用嘅格式亦要列出，停用並講明欠缺依賴。只有依賴已隨程式提供並證明離線可用、受沙箱資源限制、輸出會驗證嘅轉接器先啟用。PDF 檢查、分割、合併、擷取、排序、旋轉同中繼資料工具，要原子寫入再重新開啟核對。有損變更先披露，保留來源；覆寫要超級確認。佇列唔設人為檔案數量上限，但唔可以一次載入所有路徑或內容，有暫停、恢復、取消、當機復原同儲存空間預檢。

## 目前支援同設定

已整合受限制原生轉換器登記、檔案授權、原子輸出驗證同可取消結果日誌。已支援結構資料、文字同部分圖片，唔支援嘅 PDF／音訊／影片／封存分類另行列明。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../converters.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

原生轉換器用有界位元組偵測，每個來源上限 `32` MiB，同時最多兩個轉換；目的地需回報最少 `64` MiB 可用空間。拒絕覆寫已存在路徑，驗證來源雜湊、尺寸或編解碼輸出，原子寫入並重新開啟核對。PDF／音訊／影片／封存轉接器未支援時保持停用，並列真正原因。

## 失敗情況同剩餘工作

如實顯示缺少依賴，證明位元組偵測、離線轉接器、有界佇列、原子輸出驗證同當機復原。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
