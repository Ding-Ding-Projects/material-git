# 真實端到端程式錄影

公開功能識別碼：`screen-recording`。分類：**驗證及證據**。

## 要求嘅行為

所有有使用者介面嘅應用程式，要透過項目無頭操作路徑錄製已知提交嘅真正建置產物，提交喺自己儲存庫並喺 README 顯示。只錄製離屏桌面嘅應用程式視窗或渲染器，唔錄整部機器螢幕；展示真正端到端流程，唔只剪精華。檔案保持細小，確實過大時用儲存庫自己大型檔案路徑，唔用標準 Git LFS；介面改動就更新。

## 目前支援同設定

本次稽核未驗證已提交嘅目前版本端到端桌面錄影。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`open`；網站：`not-applicable`；儲存庫：`partial`**。請睇[實作參考](../../local-verification.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

只錄已知建置雜湊嘅真正程式視窗／渲染器，控制大小，介面改動後更新。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
