# 初始畫面顯示建置來源

公開功能識別碼：`front-provenance`。分類：**驗證及證據**。

## 要求嘅行為

所有有使用者介面嘅應用程式同 GitHub Pages，要喺初始畫面、未導覽、未開設定／關於／認證之前，顯示運行版本同嗰個版本嘅更新日期、當地時間，包含秒同有標籤時區。值必須綁定運行產物來源，唔用啟動時間、檔案時間、代理時鐘或者手寫標籤。來源缺少時，如實顯示不可用。

## 目前支援同設定

已整合產物來源；新初始畫面同網站嘅來源證據仍需完整覆核。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../build.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 控制項、預設值同限制

初始化使用綁定建置嘅 `version` 同 `builtAt`；缺少或無效時明確顯示不可用。Linux GUI 收據記錄來源 `44dc9d8dc30a4e327a98c8a6936f97a946feab55` 同建置時間 `2026-10-08T12:44:38.887Z`，唔證明網站或者已安裝 Windows 來源。

## 失敗情況同剩餘工作

導覽前顯示綁定建置嘅版本同包含秒／時區嘅時間；缺少時如實顯示不可用。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
