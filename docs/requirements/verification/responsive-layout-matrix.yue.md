# 綁定產物嘅響應式版面矩陣

公開功能識別碼：`responsive-layout-matrix`。分類：**驗證及證據**。

## 要求嘅行為

Material Designer 路徑建立嘅每個介面，都要用 `diagnose-built-ui-layout` 技能同無頭操作完成強制版面裁切檢查矩陣，綁定精確來源提交同建置產物雜湊。涵蓋一般同最小支援視窗、英文／廣東話／雙語、淺／深色，同 100、125、150、200% 顯示比例；GitHub Pages 由大約 320 px 起。原始碼檢查、模擬或者設計預覽都唔算。

## 目前支援同設定

舊無頭截圖唔證明所有新工作領域、語言同顯示比例。

呢份係有明確範圍嘅實作評估，唔代表整項要求已經完成。各個表面嘅狀態分開記錄：**桌面：`partial`；網站：`unknown`；儲存庫：`not-applicable`**。請睇[實作參考](../../scroll-surface.md)同[完整清單](../../coverage/features.json)。控制項應該放喺擁有相關資料嘅工作目的地；主要介面必須係可以實際處理工作嘅空間。

## 失敗情況同剩餘工作

喺最終提交同產物雜湊，檢查最窄／一般寬度、三種語言、兩種主題同 100／125／150／200% 比例。

缺少本機依賴、作業系統功能、遠端權限同未有驗證證據要分開報告。無法使用嘅控制項要解釋真正原因，同時保留原有資料；唔可以用虛構範例或者假成功填補空狀態。

## 私隱

個人詞彙對照、認證資料、認證標頭、私鑰同環境變數原始內容，唔會放入普通匯出、歷史、日誌、截圖或者公開文件。本機記錄使用有版本同大小上限嘅結構；敏感匯出必須經專用檢查流程。涉及外部服務嘅要求，只記錄是否存在同狀態證據。

## 驗證

清單完整性同功能行為要分開測試。只有完成呢個功能嘅原始碼及驗證覆核、需要嘅儲存／重啟檢查、反向回歸檢查，以及同一版本實際建置介面嘅操作同真實截圖，先可以將呢項要求標示為完成。Linux 證據唔代表 Windows 安裝或者認證資料儲存正常。文章翻譯亦唔代表桌面同網站每個畫面都完成本機化。
