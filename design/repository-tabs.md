# Repository tabs and explicit catalog

The tab strip represents explicitly opened repositories and utility pages. Visiting a menu destination changes the visible workspace without adding a tab. New tab and Ctrl+T open a searchable Material dialog with all menu destinations and their existing official Material icons, a native local repository picker and a GitHub repository chooser. Each search owns an adjacent anchored regular expression workbench. Cancel and Escape create nothing and return focus to the invoking control.

Local repository identity is a native SHA-256 of the canonical working-directory root, distinct for linked working trees. Aliases resolve before duplicate detection. Workspace records retain only this opaque identity and a display label. Native grants and local root paths never enter ordinary workspace persistence, history or exports. Restart restores each tab with an explicit native-picker reconnect action. The selected identity must match before the tab receives a new native grant.

GitHub repository identity binds the hostname and owner/name. Each repository owns its retained working surfaces, drafts, selection, native reviews and operation state. Navigating another repository must not change an existing surface's target. Utility pages are singletons: opening an existing page focuses it and preserves drafts. Navigation-only pages remain mounted and cached outside the tab-strip record. Repository close aggregates every owned surface and discards only those reviewed owners; busy work prevents closure.

Existing version-1 lane tabs migrate additively to utility targets while retaining IDs, titles, pinning, groups, ordering, collapse and docking. Historical records remain readable. Reopening a collapsed group's tab reveals the active tab without modifying the saved collapsed preference. Ctrl+W closes only the explicit active tab; closing the final tab leaves the current useful navigation workspace with New tab available. No replacement tab is created automatically.

Target framework: Lit with registered @material/web controls and existing Material Symbols. Source baseline: 3a83fa1fb460c861405f6eab7baf5c1ee7bec8aa. Independent design review: gpt-6-astra, approved with the identity, persistence, ownership, migration, close and focus conditions above.

Required states: empty strip; catalog full, filtered, invalid regex and dismissed; one and two local repositories; repeated aliases; two GitHub repositories; retained repository drafts; dirty close review; busy close rejection; collapsed group activation; four dock edges; restart reconnect and identity mismatch. Required tuples retain the desktop contract: normal and minimum viewport, English/Cantonese/bilingual, light/dark, and 100/125/150/200 percent display scales. Built screenshots and actual interactions are separate evidence from this design record.

Integration boundary: the shell owns app.ts, catalog routes and workspace schema. Additional repository-operation and large-file components provide independent custom elements and typed bridges. Their public routes are `repository-operations` and `large-files`; the catalog lists both when their registered components ship. A route is never advertised as implemented before it has an actionable surface.

Repository utility routes `build-tools`, `large-files`, `git-ignore` and `repository-operations` share a native-grant context chooser. Each selected repository retains its own mounted component and owner/lane scope, so changing repository does not discard hidden drafts or hide active work from close review. The chooser has an independent search and adjacent regular expression builder; an empty result leaves the current workspace intact. A native picker adds a genuine local identity, never an editable path grant. Bulk repository operations receive all available live identities and own their multiple-selection review. Installers is a global utility. Cheap LFS publication opens the existing repository Push editor only when its current task permits navigation. The catalog and Develop menu expose all five routes without implicit tab creation.
