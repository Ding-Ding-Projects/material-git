# Material Symbols

Official Google Material Symbols, outlined 24px static SVGs, Apache-2.0.

Pinned source: https://github.com/google/material-design-icons/tree/49d4db35df873165d6bd6ba09b063c7dafbac2f4/symbols/web

Each SVG is unmodified upstream source. `src/renderer/material-symbols.ts` contains its path data for local rendering without network requests.
